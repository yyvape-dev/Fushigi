# 道具・罠・階段・UI・視界の初版

2026-10-21。モンスターPR #6をmainへマージ後、7項目の依頼を本編へ統合した確認用ブランチ。

## 確認

`review.html` は部屋の照明／通路の照明／罠・アイコン／階段／持ち物UI／通常プレイを切替できる。右上で5ロケーション、階段の選択肢も確認可能。本編とセーブキーを分離している。

- ギタン、矢、店、HUDコインを画像化。既存の完成済みカテゴリ共通アイコンは維持。
- 落とし穴・地雷・睡眠ガス・空腹・ワープ・召喚の罠を生成画像で区別。
- 階段は5テーマの不透明な全マス素材。踏む行動は1ターン、選択そのものは追加ターンなし。そのまま留まり、後で再度選ぶことも可能。
- 持ち物は透過する一覧と説明・操作。矢印で選択→Enterで操作選択→Enterで実行。Escは操作から一覧、一覧からゲームへ戻る。タップも対応。選択中はターン停止。
- ダンジョンで空振りして1ターン進め、正面の隠し罠を発見する。町では攻撃不可。
- 部屋は実際の輪郭をぼかし、通路は主人公中心の円形光。未踏の部屋・通路も実際の地形を暗がりに描写する。壁の高さ・側面陰影を強め、床と区別する。描画マスクを再利用する。

## 原画と再現

`source-art/` に画像生成原画4枚、`generation-record.json` に生成記録。`build.py` が透過画像の切り出し・共通枠登録、全マス素材の切り出しを行い、`assets.json` にハッシュを記録。マップ外は天井素材で埋める。キャラや装備は反転していない。

```sh
python fushigi-experience-v1/build.py
python fushigi-experience-v1/build_review.py
python -m http.server 8000
# 別ターミナル
python fushigi-experience-v1/check.py
node tests/harness.js index.html tests/test_experience.js
node tests/harness.js index.html tests/test_mvp.js
```

実ブラウザは844×390、390×844、1280×720の5シーン、5階段テーマ、円形のぼかし、天井の模様、未踏の地形の描写、階段選択、キー／タップ操作を検証。`validation.json` と各PNGを保存。既存の主人公モーション・200階生成の検証も成功。見た目はユーザー確認前の初版。ダンジョンのさらなる美術調整は今後の範囲。
