# 5ロケーションと見下ろし描画

確認: https://yyvape-dev.github.io/Fushigi/fushigi-dungeon-v1/random-review.html

樹林・鍾乳洞・風化遺跡・氷晶洞・火山洞を、それぞれ別の原画で制作。各ロケーションに床4・壁上面2・壁正面2・階段1、合計45素材。色調フィルタだけの差分ではない。階層ごとに順番に切り替え、確認画面のロケーション選択でも比較できる。

床の縦ピッチをタイル幅の0.82にし、キャラの絵は圧縮しない。壁は上面と立ち上がりを分け、南側に床がある背面壁は高さ0.36マス、北側に床がある手前壁は0.10マスの低い切り欠きにする。地形の論理マス・移動判定・視界の計算は変更せず、カメラ・足元・道具・罠・VFXの座標を同じ投影に合わせる。

床の中央部分は複数原画を地形シードで配置し、共通下地の8px境界だけをブレンドして模様の鏡合わせを除いた。壁も2種類の原画を大きめの領域単位で選び、隣接形状と合わせて接続する。

## シレン6の調査

- [任天堂・公式ゲーム画面](https://www.nintendo.com/jp/topics/article/5ec539ee-1e2c-47cd-abd2-e8e6443d9f8f)：砂浜と水辺、鍾乳洞などの素材・高さ・見下ろし表現を実画面で確認。
- [スパイク・チュンソフト公式紹介](https://www.spike-chunsoft.co.jp/news/27997/)：火山など複数環境の画面を確認。
- [開発者インタビュー](https://www.ndw.jp/shiren6-interview-250509-01/)：3D採用、左右非対称のキャラをそのまま反転できないという制作上の話を確認。

観察できたのは、ロケーションごとの材料・形の違い、上面と側面の見える壁、単純な色替えでない環境差。正確なテクスチャ枚数、同社の素材配置アルゴリズム、カメラ角度の数値は公開画面だけでは断定しない。今回の0.82はこのゲームと承認済みキャラに合わせた制作値で、シレン6から測定した値ではない。参照画像はゲーム素材として転用していない。

原画は `source-art/`、切り出し・ハッシュは `assets.json`、再現は `python fushigi-locations-v1/build.py`。配信素材は約933KB。確認画像は `*-game.png`。
