# Fushigi 音の試聴室 v1

2026-10-21。ユーザーが町の方向を「洋風の油絵絵本ファンタジーの城下町、少し祭り感、笛と弦楽器のアイリッシュ」と指定。ダンジョンは草木の軽さ／コミカルな重厚感／不気味さと緊張を、愛嬌を残した3パターン。強化は金属のきらめき、レベルアップは笛と太鼓の祭囃子。まず候補を試聴する段階。

## 試聴

`index.html`。本編でもこの4曲・2SEを採用。こちらは独立した比較試聴ページ。4 BGMはPeriTuneの既存フリー素材、2 SEはオリジナル合成音の方向確認用試作。SEは生楽器録音ではない。選曲の意図は配布元の楽器・曲説明に基づく候補であり、音の最終判断はユーザーの試聴で行う。

| 用途 | 曲 | 配布元 |
| --- | --- | --- |
| 町 | Harvest5 | https://peritune.com/blog/2018/10/26/harvest5/ |
| 草木の探索 | Breeze | https://peritune.com/blog/2017/03/02/breeze/ |
| 軽快な地下探索 | Labyrinth | https://peritune.com/blog/2015/11/01/labyrinth/ |
| 愛嬌のあるホラー | Spook | https://peritune.com/blog/2015/09/30/spook/ |

BGM同士は排他再生、SE中はBGMを35%へ減音して終了後に復帰。自動再生なし。画面を離れたら停止し、自動復帰しない。BGM/SE音量とミュートの保存キーは `fushigi_audio_audition_v1`、本編のセーブには触れない。ループのつなぎ目ボタンで末尾5秒へ移動。

## 権利と出典

BGM：PeriTune / むつき醒。4曲とも2026年2月以前に公開された **CC BY 4.0** 曲。各曲ページの表示と [2026-10-21に確認した公式条件](https://peritune.com/about/) により旧曲への同ライセンス継続適用を確認。新曲の独自条件とは混同しない。

ライセンス：https://creativecommons.org/licenses/by/4.0/ 。公式ループ版MP3をzipから取り出すか単体MP3から取得し、音声ファイルの加工なし。曲名・作者・元ページ・ライセンスを画面内にも表示。取得URL・zip内パス・SHA-256は `sources/bgm.json`。クレジットは本編接続時にも引き継ぐ。

SE：本プロジェクト向けの手続き的な合成音。既存ゲームの旋律・録音・サンプルは不使用。`render_se.py` は固定乱数で金属の非整数倍音、息成分付き笛の音色、減衰する打楽器を合成。`sources/se.json` に出力ハッシュを記録。

## 再構築・検証

```sh
python fushigi-audio-v1/fetch_bgm.py
python fushigi-audio-v1/render_se.py
python -m http.server 8000
# 別端末
python fushigi-audio-v1/check.py
```

SE生成はnumpy、検証はPlaywrightとChromiumを使用。3画面サイズで6音源を実ブラウザでデコードし非無音を確認。再生切替、SE減音と復帰、ミュート、ループ設定、停止、音量設定保存、初回自動再生なしと画面内収容を検証。`validation.json` と `audition-*.png` に保存。デコード成功は音色・曲調の聴感評価とは区別する。

2026-10-21に本編接続をユーザーが承認。`assets/game-audio.js` と本編の実イベントで接続済み。町／5ロケーションの曲切替、強化・レベルアップ、設定、入力による開始と非表示時の停止は `check_runtime.py` で検証。保留：通常操作／戦闘のSE。旧装備サイズ修正PR #9は別件のまま。


## アクションSE追加（2026-10-24）

`assets/action-sfx.js` に16種類（斬撃、命中、会心、被ダメージ、道具拾得、ギタン、投擲、壺破壊、罠の踏み込み、罠6種類の結果、鍛冶）を追加。本編は既存の強化・レベルアップと合わせ18種類。試聴室の追加ボタンで個別再生できる。

追加分は録音・外部サンプル不使用のオリジナルPCM合成音。Web Audioで必要時に生成・キャッシュし、外部素材のダウンロード不要。既存BGMのクレジットとCC BY 4.0条件は上記のまま。SE生成用乱数は独立した固定シードで、ゲームの乱数・セーブに影響しない。生の陶器・金属の録音ではないため、音色の好みは実機試聴で調整する。

同時発音は最大8音、同一音の55ms以内の連打を抑制。SE中のBGM減音、音量保存、ミュート、画面非表示で停止に対応。罠の結果音は `triggerTrap`（VFX結果適用時）で発音。地雷で実際にダメージを受けると被ダメージ音も重なる。投擲と壺破壊は現行の即時計算に合わせて重なる。鍛冶は成功時のみ3打の金属音。

検証：`node tests/harness.js index.html tests/test_action_audio.js`、MVP、壺、城下町、交互攻撃がALL OK。`python tests/check_action_audio.py` はChromiumで全16音の実出力、PCMの非無音・有限値・ピーク、同時発音上限、ミュート・音量0・停止を確認し `action-validation.json` に記録。音色の聴感・iOS実機は未確認。

## SE全体追加（2026-10-24、v2）

PR #68はmainへ反映・Pages成功。追加38音により、PCM合成54種類＋既存の強化／レベルアップ2音で合計56種類。

- 味方：クナイ／剣／黒魔法を鳴り分け。一閃、狐火の襲、加入、レベルアップ、被ダメージ、離脱。
- 敵：通常・遠距離攻撃、回避、撃破、炎、雷、鈴、砲撃、進化、ミミック、盗み・店の警報。
- 道具：食事、飲む、回復、巻物、杖、装備、識別、合成、置く、壺・倉庫の出し入れ。
- 冒険・町：復活、死亡、踏破、階段・出発、扉、宿の回復、売買・精算・預金、メニュー・会話、足音。

足音は他SEの再生中に重ねず、音量を下げ、足音と短いUI音ではBGMを減音しない。最大8音に加えコンプレッサーで同時再生のピークを抑える。視界外の敵の発音を抑制する。死亡時はBGMだけを止め、死亡SEを途中で切らない。BGM取得失敗でもSE入力をロックしない。

自然回復・待機・保存・画面更新、画面外のNPCの移動は静かに保つ。音はセリフではなく実アクションの関数から発火し、加入失敗や売買失敗で成功音は出さない。既存録音のコピーや外部サンプルは使用しない。

環境の接続切断後、GitHub経由で変更を復元。V8のCanvasスタブで味方47／アヴェニウス42／シェリニーニャ43／砲撃82／壺／街／交互攻撃／店／途中保存と追加の音イベント回帰を実行。全54音のPCM有限値・非無音・ピークを確認。記録は `action-v2-validation.json`。ネイティブCanvasのMVPと実Chromiumの54音確認は `.github/workflows/audio-regression.yml` で実行する。実機の聴感・iOS確認は別途。
