# 移動操作・メニューの初版

2026-10-21。PR #7本番採用後、ユーザー指示でダンジョン内店舗を後回しにし、移動・メニューを先行。

## 確認

`review.html` は本編と同じコード＋場面選択。セーブは本編と分離。通常プレイへ切替可能。`assets/controls-ui.js` とCSSを本編へ接続している。main未反映の確認用ブランチ。

- タッチ：向き／斜め／走るを押して切替。同じボタンで通常移動へ戻る。向きモードの中央は近い敵へ向く。走る＋方向は押している間のみ。
- キー：Ctrl＋方向は向き、Alt＋斜め方向は斜め固定、Shift＋方向はダッシュ。矢印の同時押しで斜め入力。Fで近い敵へ向く。従来のWASD／vi／テンキーも維持。
- ダッシュ：敵・壁・階段・既知罠の手前で止まる。道具／ギタン上は自動拾いなしで停止。分岐と部屋への入口で停止。ダメージ／転送・睡眠／混乱・目つぶしでも連続移動を止める。解除・メニュー・画面非表示でタイマーを止める。安全停止後は一旦離すまで再開しない。
- Esc／メニューボタン：持ち物、足元、状態、地図、履歴、設定、操作ガイド。方向・メニュー選択は0ターン。子画面から戻るとメニュー、さらに戻るとゲーム。持ち物の操作選択中は一覧へ一段戻る。Iで直接開いた持ち物はEscでゲームへ。
- 設定の上下キーで操作項目へフォーカス。持ち物のPageUp／PageDownでカテゴリ切替。

公式参考：[シレン6・基本操作](https://www.spike-chunsoft.co.jp/pages/shiren6/guide/)。ブラウザ／タッチへの割当と安全停止条件はFushigi用の実装。既存の店の処理、新しい店主、新モンスターはこの変更に含まない。

## 再現・検証

```sh
python fushigi-controls-ui-v1/build_review.py
python -m http.server 8000
# 別端末
python fushigi-controls-ui-v1/check.py
node tests/harness.js index.html tests/test_mvp.js
```

実ブラウザ844×390／390×844／1280×720で `tests/test_controls_ui.js` を実行し、方向変更、斜め制約、金／矢の上で拾わず止まる、既知罠／階段／敵／分岐で停止、停止後の自動再開抑止、メニューで中断、戻る階層、Ctrlのキー操作とタッチ、設定項目選択を検証。画面とvalidation.jsonを保存。既存の階段・持ち物などの3サイズ検証も成功。見た目は初版としてユーザー確認対象。

## 両手・片手のデザイン更新

濃紺ガラスと金の縁へ統一。メニューの「操作配置」で自動／両手／右片手／左片手を選ぶ。自動は横で両手、縦で右片手。横での片手選択も保存される。方向パッドそのものを反転せず、グループの配置を左右で変える。押下とモード固定中を色で区別。常設の履歴をメニューへ集約し、メニュー下部の選択・決定・戻るを片手の側に置く。確認は `python fushigi-controls-ui-v1/check_hands.py`。390×844、844×390、320×568の3サイズ×3配置。画面内収容・タッチのメニュー階層・保存・自動選択を検証。実機での握りやすさはユーザー確認対象。

## 操作盤のグラフィック

配置承認後、`assets/control-skin.css` で石板・真鍮の縁・留め具、浮き彫り矢印と剣の紋章を追加。CSSと同梱SVGで再現し、遠隔画像へ依存しない。押下は沈み込み、固定モードは灯りで識別。座標・ヒット領域と動作は変更していない。9配置の確認画像を更新。
