# enemyC：深層6系統＋アビスロードの基準絵

## 敵の顔つきへの修正

ユーザーの「各種敵キャラであることを意識して。顔つきが味方キャラになっている」を受け、ニンジャ・まじゅつ師・すず坊主・おおづつ兵を各初稿PNG参照で再生成。細く鋭い目、険しい眉、不気味な顔・薄笑いへ変更。大きな瞳と頬の赤みを抑え、立体感・装備・斜め上からの右向き視点は維持。ミミック・いかずち岩・アビスロードは既存の怪物の顔を維持。各修正の全指示と参照は `enemy-face-prompts.json`、参照PNGと原画は `source-art/`。今後の生成でも味方顔に戻らないよう `sheets.js prompt enemyC` の表情指定も修正。

2026-10-23。ユーザー指定の `node tests/tools/sheets.js prompt enemyC` を起点に、OpenAI image_gen で7体を制作。ラナの採用済みSE絵を画風の参照に使用。

- `art/`：7体の256×256 RGBA基準絵。足元原点(128,224)、外形高さ最大192px、幅最大224px。右向き斜め前の1方向。
- `enemyC.png`：4列2行に再配置した透過シート。
- `preview.html`：拡大・ラナと並べた128pxキャンバス比較・明背景への切替・個別ダウンロード。
- `source-art/`：加工前の原画。シート初稿、未採用の透過修正試作、単体で生成し直した大砲兵と主。初稿で大砲と翼が接したため、この2体は初稿を参照して単体化した。
- `prompts.json`：指定プロンプトと修正／単体化の指示。最初の生成には「ラナは材質・柔らかい立体感・頭身・視点の参考、本人を描かない。4列2行、8番目は空、枠内に全身を収める」の補足を追加。
- `manifest.json`：原画と参照のSHA256、切り出し位置、画像の倍率・アンカー。
- `build.js`：背景につながったマゼンタだけを除去（魔術師の紫の玉は保持）、つながった画素の領域で切り出し、縦横比を保って登録。大砲兵と主は生成済みの透過を維持。再現：`node fushigi-enemy-c-v1/build.js`。

今回はキャラクターデザインの基準絵を制作。本編の描画コードや出現表・能力・セーブは変更していない。8方向・歩行・攻撃、6系統の上位3色、本編への差し替えは次工程。新画像は `art/` に隔離しており、基本種だけが先に差し替わる状態にもしていない。mainへの反映・公開は未実施。
