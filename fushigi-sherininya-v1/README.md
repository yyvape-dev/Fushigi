## 承認済みデザイン

2026-10-22。ユーザー添付から白髪、黒/青緑のフードと裏地、金縁の短い黒い服、白い袖、黒い手袋とブーツを制作。ユーザー修正の薄朱色アイメイク、可愛い淡い目のクマ、少しふっくらした胸元と太ももを採用。半目で眠そう・気だるそうな表情、片目にかかる前髪、落とした肩を維持する。`source-art/approved-design.png` を固定基準とし、「そのままつくりあげて」で動作から本編統合まで一任された。

## マネキン・素材・登録

ラナの元マネキン `fushigi-direction-base/make_direction_guides.py` と幾何ヘルパーを再利用。頭・胴・脚・足・約26度の正投影を維持して、肘と手首を魔法用に変更した。待機では手を低く構え、歩行では脚と腕を動かし、詠唱では手を進行方向へ伸ばしてもう一方を体へ添える。剣の攻撃モーションは使わない。手の投影メタデータは実際の関節位置から取得。Blenderモデルと各方向ガイドは `guides/`、再現は `make_guides.py`。

方向順S/SW/W/NW/N/NE/E/SE。確定待機8方向をそれぞれ参照して歩行8・詠唱8を生成し、反転なし。全24ポーズ。歩行・攻撃は専用1ポーズと確定待機を交互に使う。300msの攻撃のうち35〜240msが詠唱専用画像、開始/終了は待機そのもの。魔法は両手を使う。原画の手元に小さな黒紫の魔力を描き、長い射線は本編で重ねる。

待機は256×256・原点(128,224)、動作は320×256・原点(160,224)、640×256アトラス。シートごとに共通倍率を使い、靴の下部6.5%のアルファ100以上から接地点を測る。外形中央や魔力の位置で身体を登録しない。正面はラナの頭頂基準y=33に合わせる。フードの形を含む方向差は測定値として保存し、コマ別の身体変形や方向別拡大縮小で隠さない。描画倍率1.00。比較ページのラナは本編採用済みv3実画像を使い、生成デザイン画のラナを本編へ持ち込まない。

原画・ガイド・生成プロンプト/参照/ハッシュは `source-art/`・`guides/`・`generation-record.json`。登録情報と全画像のハッシュは `ally.json`。ラナ、武器12種、盾10種、敵60種、ユズナミキとアベニウスの原画/倍率/接地点は変更しない。

## 黒魔法

ユーザー指定：2マスまで離れた敵へ貫通攻撃。仲間へダメージなし。

実装補完：8方向の直線上、距離1〜2マスの敵に毎ワールドターン1回。敵や主人公を貫通し、敵だけを攻撃。床の道具/罠は遮らず発動もしない。壁や塞がれた斜め角では止まる。3マス先・直線外には届かない。敵が多く並ぶ射線、同数なら近い敵を優先し、1回で最大2体。魔物部屋の未覚醒敵は対象外。黒い中心と淡い紫の縁の射線を300ms描き、攻撃中の向きは固定する。

対象はダメージ前に敵オブジェクトで固定。手前の敵が倒れても奥へ当たり、途中のミスでも射線を止めない。分裂して新たに生まれた個体を同じ詠唱で重ねて攻撃しない。命中とダメージ乱数は対象ごとに既存式を使い、敵の守備も適用。倒した敵ごとに主人公/本人へ経験値を各1回与える。主人公や他の仲間を対象配列に入れず、友軍へのダメージ処理を持たない。

眠り中は詠唱せず、混乱時は既存の混乱行動。気だるい外見を理由とするランダム休止は追加しない。狐火や一閃は使わず、主人公の倍速による無料手番でも詠唱しない。

## 遭遇・同行・成長

2階以降の未同行/未撤退時、各階25%で助っ人に遭遇。候補はユズナミキ/アベニウス/シェリニーニャの均等3択。同時同行上限は従来の1人を維持する。会話で任意加入/保留、0ターン。顔・名前・台詞・HUD・状態が本人へ切り替わる。追従/入れ替え/階段同行/敵からの攻撃・状態異常/撤退は共通処理。体力が尽きるとその冒険では再加入しない。町・新しい冒険で同行と成長をリセット。現在の本編は冒険途中を保存しないため新しいセーブ形式は増やさない。

本人Lvは生成時の主人公と同じ。HP24＋4×(Lv−1)、最大Lv30、レベルアップでHP＋4。攻撃＝主人公の現在の攻撃＋2＋(本人Lv−1)を四捨五入、毒を引いて最低1。守備＝主人公の現在の守備−2＋⌊(本人Lv−1)/3⌋、最低0。装備は黒魔法とフード服で固定、主人公の武器の絵や印はコピーしない。数値は本作の初期調整。

会話は眠たげな短い台詞を追加し、ユズナミキのユーザー指定台詞は維持。縦右手は仲間HPを左下、縦左手は右下、横は右上。HUDの長い名前は省略表示し、会話/状態では全文を表示する。
