- [本編](https://yyvape-dev.github.io/Fushigi/)

## 強さと行動

同じ階で比較したHP倍率は1 / 1.35 / 1.75 / 2.2。攻撃は1 / 1.18 / 1.4 / 1.65倍を切り上げ、段階差0〜3を加算する。守備は段階ごと+1、経験値は1 / 1.6 / 2.4 / 3.5倍。最上位の出現重みは基本の65%。既存の分裂・盗み・毒・壁抜け・倍速／鈍足などの個性を引き継ぐ。

上位の矢は射程最大7、炎は最大5。炎・自爆の威力、睡眠／混乱の長さも段階に応じて強化。分裂した個体は色・能力を維持。コウモリと毒バチの全段階は浮遊特効の対象。色名は属性攻撃の変更を意味しない（あおドラゴンも炎を吐く）。

`assets/monster-roster.js` が本編の既存定義から60種を作り、`catalog.json` は同じ定義から書き出す。元の基本キーを維持するため既存セーブの敵も専用絵で表示できる。

## 絵とモーション

スライム・毛のないゴブリン・コウモリの承認済み原画と動作はv1を参照。残り12系統は新規に3D方向／ポーズガイドと承認済みキャラを参照して生成した。原画25枚（待機12、動作12、弓の前後修正1）を保存。

新規分は待機96方向画像と、歩行／攻撃192ポーズ。256pxの共通キャンバス、足元(128,224)、種ごとの共通倍率。浮遊種は原画内の接地位置を上げる。新12系統の動作は各方向で待機＋歩行1ポーズ＋攻撃1ポーズを切り替える構成。元3系統の既存4ポーズアトラスは維持する。画像を引き伸ばして動作を作らない。

対称な11系統はS・SW・W・NW・Nを基準として反対側3方向を反転（ユーザー許可済み）。ゆみこぞうは左手の弓／右手の矢を維持するため8方向を個別使用。S/N攻撃は別原画で前後への射撃に修正した。

色替えは生成を繰り返さず、同じ画像の輝度・陰影とアルファを保つ決定的な色変換。暗い瞳を保ち、白いハイライトは滑らかに残す。192フレームのキャッシュ上限を設けた。主人公・武器12種・盾10種の承認済み画像と描画処理は変更していない。

## 制作物と再現

- `generation-record.json`：全プロンプト、参照、原画と参照のSHA256。
- `guides/`：Blenderモデル、方向・動作ガイド。`make_guides.py` / `make_motion_guides.py` で再現可能。
- `source-art/`：加工前の生成PNG。修正前の弓動作も履歴として保持。
- `build.py`：透明な間隔で原画を分割、小さな独立ノイズを除去、原画ごとの解像度差を補正し、種共通倍率で登録。各方向を個別の大きさに変形しない。
- `monsters.json`：各系統の登録値、画像パス、ハッシュ。
- `build_catalog.py` / `build_review.py`：図鑑データとセーブ分離したゲーム確認画面を再生成。
- `*-motion-contact.png`：基本種／最上位×待機／歩行／攻撃×8方向を実レンダラーで描いた目視確認画像。

```sh
python fushigi-monsters-v2/build.py
python fushigi-monsters-v2/build_catalog.py
python fushigi-monsters-v2/build_review.py
python -m http.server 8000
# 別ターミナルで：Pillow / numpy / Playwright / システムChromiumを使用
python fushigi-monsters-v2/check.py
node tests/harness.js index.html tests/test_monster_families.js
node tests/harness.js index.html tests/test_mvp.js
```

## 確認結果

60種の階層制限・全種出現・段階ごとの能力増加・分裂時のランク維持・特殊AIを検証。実ブラウザで1,440通り（60種×8方向×3動作）の非空描画・色の区別・アルファ不変、12系統すべての実歩行／攻撃コマを検証した。15系統の動作比較を目視確認。横844×390／縦390×844の本編確認画面で敵の配置・AI・移動／攻撃の描画接続に成功し、JavaScript例外なし。既存MVPもALL OK。結果は `validation.json`、画面は `game-landscape.png` / `game-portrait.png`。
