# 旅人3人の歩行と、友好的NPCの会話方向

2026-10-25。ユーザー依頼：3人も他の仲間同様歩き、敵以外のNPCは話しかけると主人公へ向く。

- 旅人の `DungeonNPC.tick()` は既存の未加入仲間と同じ世界ターンへ接続。1ターンにつき最大1歩、現在の向きへ70%優先、他は8方向の有効候補から選ぶ。
- 主人公の隣は会話のため停止。メニュー・会話・死亡中も止まる。道具・罠・敵・仲間・別のNPC・店・魔物部屋・階段・通路を避ける。入口や1マスの狭い場所を占有しない。
- 位置を100ms基準で補間し、220msの歩行中は80msごとに待機／歩行のコマを切り替える（既存仲間と同じ方式）。サービス利用後も歩く。
- `facePlayer()` を旅人・既存仲間の会話、ダンジョン店主、町の住民・傭兵・施設・宿の主人へ接続。会話中は歩行・古い攻撃姿勢を停止。固定店員のカウンター位置の補正は変更しない。
- 途中保存は現在地・向き・使用済み・要求品・報酬を維持し、読み込み後の補間位置と歩行時刻だけ静止へ揃える。旧保存のフィールド不足は初期値で扱う。

## 画像

採用済み `../fushigi-npcs-v1/source.png` を参照して、同じ4列×6行の各方向を片足を前へ踏み出す歩行姿勢に編集。原画は `walk-source.png` に保持。歩行24点は `../fushigi-npcs-v1/assets/<kind>/<direction>-walk.png`（256×256 RGBA）。待機24点は上書きしない。

プロンプト：元の24人の顔・髪・体格・衣装・装備・色・カメラ・縮尺を維持。1歩の穏やかな歩行姿勢へ。ユルサは右手にハンマー、カミールは衣の裾から踏み出す靴、イアルマスは左腰の刀とマントを維持。列と8方向の対応は元画像と同じ。単色#FF00FF、床影・文字なし。

再出力：`python fushigi-npcs-walk-v1/build_walk.py`。生成画像の各列のマゼンタの隙間で行を分割。元の待機画像から方向別の倍率を取り、歩行へ同じ倍率を適用する。頭の左右位置と足元(128,224)を揃える。ポーズ別の高さへ引き伸ばさない。原画・採用見本・全24点のハッシュ、共通倍率、領域は `walk.json`。

`walk-contact.png` は歩行24方向、`walk-preview.gif` は待機と歩行のループ（実ゲームより遅い160ms間隔の確認用）。歩行コマの体の高さは姿勢で変わるが、倍率は同方向の待機と共通。
