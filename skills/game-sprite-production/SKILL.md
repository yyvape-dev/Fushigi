# ゲーム用画像アニメーションの基本手順

ユーザーが承認した Fushigi の制作方法を再利用する。ゲーム内での実用性を基準に判断する。

## 最初に固定すること

- 実ゲームの表示サイズ、カメラ、足元の原点、キャンバス寸法を先に決める。
- 簡易3Dマネキンでサイズとポーズを取る。マネキン自体の装飾には時間をかけない。
- アニメーションより先に、全方向の待機基準絵を確定する。非対称な装備は左右反転で済ませない。
- 武器・盾を別画像にする前提で、解剖学的な左右、握り位置、前後関係を設計する。

## 画像生成とモーション

- 各方向・各修正の生成には、必ずその方向の確定基準絵を参照する。別方向や直前の生成結果だけを参照して連鎖させない。
- 基準絵とポーズガイドを併用する。参照元、生成結果、ハッシュを記録する。
- 小さいサンプルで動きを確認してから展開する。崩れたコマは個別修正し、承認済みの品質を必要以上に作り直さない。
- 元画像を保存し、透過・切り出し・位置合わせは再実行できるスクリプトにする。
- 同一方向のシートは共通の等倍比率で扱う。足の接地と体格を確認する。頭だけを合わせて足を浮かせない。
- 待機に戻るコマは確定基準絵をそのまま使う。隠れたコマ別変形で動きを取り繕わない。

## 別画像の武器・盾

- 最初は標準の片手剣1本と盾1枚で、待機と攻撃を一通り成立させる。その後に装備種類を増やす。
- 各コマに左右の手の位置、装備角度、前後の描画順、必要な遮蔽マスクを持つ。
- 握り座標が合うだけでは合格にしない。実際の装備画像を載せ、親指・拳・手首・前腕の向きと、顔・髪・胴体への食い込みを見る。
- 盾を持つ腕が手前になる方向では、肩→前腕→手首→拳のつながりを保つ。拳だけの小さいマスクで重ねると、前腕が盾に隠れて手が浮く。まず盾全体を腕の後ろへ置き、必要な場合だけ腕全体に沿ったマスクを使う。
- 描画順のログが正しいだけで修正完了としない。装備付き全コマの実画像で腕の連続性を見る。元画像との画素比較は期待する遮蔽を具体的に検証する補助に使う。
- 特に振り抜きと戻りのコマは必ず装備付きで確認する。素手の見た目だけで「持てる」と断言しない。
- 盾は表・裏・側面を用意し、腕を隠す範囲を確かめる。単一画像の横つぶしや簡易手袋マスクは検証用と区別する。
- 武器も必要な視点を描き分ける。回転だけで全方向を代用できると仮定しない。
- 両手武器、槍、弓などは片手剣と同じ握り・モーションで成立するか別途判断する。

## ゲーム内での検証と納品

- 拡大静止画、連続再生、実ゲームの表示サイズで確認する。装備なし／ありの両方を見る。
- 攻撃中の向きを固定し、入力・ダメージ・効果音・エフェクトとのタイミングを確認する。
- 透過、端の欠け、足元、方向、開始終了コマ、読み込み、描画順を必要な範囲で検証する。座標テストは視覚品質の保証とは区別する。
- 原画、スプライト、メタデータ、再現スクリプト、プレビューを残す。仮装備と本番装備、ローカル統合と公開・pushの状態を明記する。

Fushigi の具体的な値と制作状況は [references/fushigi.md](references/fushigi.md) を参照する。
