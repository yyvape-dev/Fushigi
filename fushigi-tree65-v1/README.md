# 65°固定：描き込んだ木と現行3Dの比較

ユーザー方針：カメラは65°固定。見えない裏側を作るより、見える面の立体感・陰影を2Dで描き込む。今回の範囲は木1本の仕上げと同じ条件での比較。本編の表示方式をこの段階で切り替えてはいない。

## 成果物

- `assets/dungeon/forest-fixed65-v1/tree.png`：512×512、RGB、単色マゼンタ背景。広い不規則な樹冠、幹と根、木自身の陰影を描き込んだ65°用の絵。ランタンは木へ焼き込まず、別部品として使う想定。
- `source-art/tree.png`：生成原画。採用した森のコンセプトを参照して生成。プロンプトと参照元は `generation.json`。
- `compare.html`：左に本編と同じ3Dモデル生成関数、右に生成絵を置く。同一の65°正射影・地面・照明とし、見える部分の画面上の高さと足元を一致させる。右の縦横比は維持するので、横へ広がる樹冠はそのまま評価できる。
- 右の木は描き込んだ陰影を使用し、地面には別の柔らかい接地影を加える。左は実際の立体形状から影を落とす。右の木の陰影は動く点光源には追従しない。
- 160px／280px表示を切り替え可能。狭い画面は全体が入るよう両者を同じ比率で縮小。回転操作や別角度の制作は行わない。

## 確認

Chromium/SwiftShaderで、左右の可視領域の高さと足元の投影位置を実測。160px・280px・390px幅で一致。`validation.json` に測定結果。ページ例外なし。

`compare-160.png`・`compare-280.png`・`compare-mobile.png` は生成イメージのモックではなく、この比較ビューを実際に描画した画面。

比較ビューを開くにはリポジトリルートでHTTPサーバーを起動し、`fushigi-tree65-v1/compare.html` を開く。元画像から配布画像への処理はRGB化と512pxへのリサイズのみ。背景色の透過は比較ビュー内で行う。

## 次の制作

採用した木を基準に、65°・縮尺・足元位置を統一した環境小物を8〜12個ずつシート生成し、`tests/tools/sheets.js` と同じ考え方で切り分ける。地形に影響しない壁際配置と、階段・通路の保護を引き継ぐ。
