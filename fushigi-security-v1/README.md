# 店の番兵・番犬：初期デザイン

2026-10-22。ユーザーが参考の青い制服/銀の兜/槍/丸盾の王国騎士を提示し、盗むと湧く非常に強い番兵を指定。番犬もシレンらしい厳つさを取り入れる依頼。

[初期デザイン](source-art/initial-design.png) / [確認画面](preview.html)

- 番兵：青いキルト服、銀兜と肩当て、右手の長槍、左手の青い丸盾。幅のある体格でラナと同じゲーム用頭身。
- 番犬：茶とクリームの毛、短く太い脚、大きな顎と小さな牙、鋲と金具のある太い首輪。四足。
- 役割：盗みの発覚時に出現する追手。通常の敵より格段に強く、犬は速さ、兵は耐久と攻撃力を重視する予定。具体値は未実装。
