# 番兵・黒い番犬：盗難時の追手

ユーザーが番兵と番犬のデザイン・公開を承認し、番犬は黒へ変更するよう指定。番兵は青服・銀兜・右手の槍・左手の青い丸盾。番犬は黒い毛に灰色の口元、太い首輪、筋肉質な短足の四足。

- [本編](https://yyvape-dev.github.io/Fushigi/)
- [デザイン・8方向と動作](https://yyvape-dev.github.io/Fushigi/fushigi-security-v1/preview.html)
- [盗難・階移動の確認用](https://yyvape-dev.github.io/Fushigi/fushigi-security-v1/game-review.html)（別セーブ・高HP）

## 挙動

`assets/shop-security.js` と本編の敵AI・戦闘へ接続。盗難時は階段付近の空き床に最大4人の番兵、主人公から離れた到達可能な床に2匹の番犬が出現。16ワールドターンごとに1体を追加、同時上限12体。占有床・壁・道具・罠には出さない。出現ターンは攻撃/移動しない。通常の敵の出現抽選には含めない。

- 番兵：HP240、攻撃48〜60、守備22。等速。
- 番犬：HP160、攻撃32〜42、守備14。1ワールドターンに最大2マス移動、攻撃は1回。
- 視界から外れてもその階では追跡する。壁と角・他の敵・仲間・店主を通り抜けない。既存の攻撃・杖・状態異常・仲間の攻撃で対処可能。
- **ユーザーの訂正により、階を移れば追跡は終了。** 次の階へ敵対/増援状態を持ち越さない。前の階の店主も移動しない。
- 無限増援を経験値稼ぎにしないため、番兵・番犬の撃破経験値は0。

強さは本作の数値に合わせた初期調整。本家の値をそのまま流用したものではない。

## 本家の確認と今回の採用

[シレン6 Wiki：泥棒テクニック](https://shiren6.game-info.wiki/d/%C5%A5%CB%C0%A5%C6%A5%AF%A5%CB%A5%C3%A5%AF) を2026-10-22に確認。
入口脇で待機し、未精算品を持つと出口を塞ぐ、複数店主が同時に敵対する、場所替えだけでは敵対しない、盗難時に階段周囲へ番兵が出現し出現ターンは攻撃しない、番犬は倍速という挙動を参照した。
今回はユーザー指定に合わせ、各入口に必ず1人を置く。階を移ると追跡が終わる仕様もユーザー指定を優先。未実装の壺・壁掘り・大部屋などは追加していない。

## 制作・再現

ロックした初期デザイン→犬の黒色版→元ラナの人型マネキン/四足の簡易モデル→8方向待機→対応する待機とポーズガイドから歩行/攻撃。
右槍/左盾を保つため反転なし。番犬も全8方向を個別に制作。計48ポーズ。
番兵は槍の余白を含む512×320、原点(256,280)、本体の身長191基準。犬は256×256、原点(128,224)、耳まで128基準。本編はラナと同じ描画倍率1.00。
元シートごとに共通倍率とし、靴/肉球の帯から接地点を測る。SE歩行の持ち手とS攻撃の向きを単体原画で修正し、槍が隣セルへ混ざった初回攻撃シートは不採用。2列×4行の広いシートで修正。単体修正の元解像度補正もメタデータに記録。犬のセル境界の隣コマの断片は最大連結成分で除外。

```sh
blender -b -t 2 --python fushigi-security-v1/make_guides.py
python fushigi-security-v1/build.py
python fushigi-security-v1/check_art.py
python fushigi-shops-v1/build_review.py
python fushigi-security-v1/build_review.py
node tests/harness.js index.html tests/test_shop_security.js
python -m http.server 8000
# 別ターミナル
python fushigi-security-v1/check_browser.py
```

30項目の追手・複数入口検証、店40項目、既存仲間36/42/43項目、本編MVP、48画像の透過/端/方向/動作/ハッシュ、縦390×844・横844×390・小320×640の実ブラウザを確認。
原画・比較・実ゲームの攻撃コマを目視確認。結果は `art-validation.json` / `browser-validation.json`、全コマは `all-poses.png`、実ゲーム描画は `game-poses-*.png`。
ラナ・承認装備12武器/10盾・既存敵60・仲間3人の原画と倍率は維持。
