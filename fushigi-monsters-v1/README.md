# モンスター3種・待機基準絵 v1

2026-10-20。スライム・ゴブリン・コウモリの待機8方向を制作した初版。ユーザー確認前で、本編の敵描画にはまだ接続していない。歩行・攻撃は基準絵の確認後に制作する。

## 顔の簡略化（最新修正）

ユーザーから「敵らしい目や顔つきにし、可愛い系統でも添付画像くらい簡略化してほしい」との指摘。ゴブリン・コウモリの色付き虹彩・細かいまぶた・表情を除き、黒い楕円の目、小さな白いハイライト、短い口、単純な牙に整理した。黄色い丸いモンスターの添付は顔の情報量の参考にし、色や体型はコピーしない。スライムは初版から簡潔な顔のためそのまま。

修正原画は `source-art/faces-v2/`、生成2回の参照とプロンプトは同フォルダの `generation-record.json`。ゴブリンはSE右手修正を反映したシートから編集した。初版原画も保持。現在の `build.py` は顔修正シートを読み、同種内共通倍率で登録する。ゴブリンの棍棒の持ち手とコウモリの左右反転も維持。初版画像は `before-face-v2/` に保存し、確認画面の「顔」で修正版と初版を切り替えられる。画像生成でシートを編集したため、顔以外にも描き直しによる小差分がある。

24画像と6反転一致、初版/修正版切替、床5種、8方向、3画面寸法を再検証。顔の採用はユーザー確認待ち。

確認画面: `preview.html`。主人公と同じ実寸、5ロケーションの床、8方向、2倍表示、方向の自動切替（静止画比較）を用意した。スマートフォンでは比較ステージを横にスクロールできる。

## 制作基準

- 承認済み主人公 `fushigi-direction-base/assets/hero-base/SE.png` を画風の参照にし、約26度の平行投影で簡易3Dガイドを制作。
- 各画像256×256 RGBA。地面原点(128,224)。本編と同じ1マス64px・主人公の頭頂〜足元96pxで比較する。画像全体を96pxに縮める方式ではない。
- スライムは高さ約46px、ゴブリン約77px、コウモリ約56px。コウモリは地面原点より14px上に浮く。体格は今回の提案であり承認待ち。
- スライム・コウモリは S / SE / E / NE / N を生成し、SE→SW、E→W、NE→NWを水平反転して8方向に展開。ユーザーによる反転許可を適用。初版の方向シートは計18方向、納品は24方向。後から顔修正シートを追加。
- ゴブリンは右手の棍棒を維持するため8方向を個別生成。初版SEだけ左手になっていたため、SEの3Dガイドと元原画を参照して単独で修正した。
- 同一種のシートは共通倍率。初版ではSE修正原画のみ解像度が異なるため、元シートの体高へ一度合わせてから共通倍率を適用した。顔修正版は修正済みSEを含むシートを一括登録する。方向ごとの隠れた伸縮や揺れで補正しない。
- 原画の孤立したアルファノイズを除去し、アンチエイリアスを保持。コウモリの翼が均等セル境界を越えていたため、余白の実際の位置で切り分けた。

## ファイル

- `source-art/`: 未加工の生成原画3枚とSE修正前後。生成結果は上書きしない。
- `guides/`: 3Dガイド、方向別PNG、参照シート、Blenderファイル。
- `generation-record.json`: 全4回の生成プロンプト、参照、出力。
- `assets/{slime,goblin,bat}/`: 24枚の登録済み画像。
- `monsters.json`: 原点、倍率、反転元、SHA-256、SE修正参照。
- `*-contact.png`: 全方向比較。
- `review-*.png` / `validation.json`: ブラウザ確認結果。

## 再現

リポジトリルートから実行。画像生成そのものは同一バイトでの再生成を保証しないため、保存原画を再利用する。

```sh
blender -b -t 2 --python fushigi-monsters-v1/make_guides.py
python fushigi-monsters-v1/make_guide_sheets.py
python fushigi-monsters-v1/build.py
python -m http.server 8000
# 別のターミナルから（Pillow / Playwright / /usr/bin/chromium）
python fushigi-monsters-v1/check.py
```

24画像の透過・端の欠け、6画像の反転一致、全8方向・床5種・実寸/2倍切替、1100×900 / 390×844 / 844×390の読み込みとページ幅を確認。実画像でゴブリンの持ち手、コウモリの翼、主人公との体格も確認した。ゲーム内のAI・移動・戦闘との接続と実機確認は次工程。
