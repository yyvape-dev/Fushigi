# モンスター3種・歩行/攻撃 v1

2026-10-21 JST。ユーザーが顔とデザインを採用し、ゴブリンは髪なしに変更する指示。髪なし8方向を登録後、3種の歩行・攻撃を制作した。

## 範囲

- スライム: 伸縮する移動、溜めて伸びる体当たり。
- ゴブリン: 左右の足運び、右手の棍棒を振り上げて振り下ろす。全コマ髪なし。
- コウモリ: 羽ばたく飛行、溜めから前へ噛みつく。
- ゴブリン8方向＋スライム/コウモリ各5方向=18生成シート。各シートは歩行2・攻撃2の4コマ、計72生成コマ。左右反転で24コマを補い、8方向×3種×4の96コマ、24アトラス。
- 歩行は2ポーズと採用済み待機を交互に再生する4コマ初版。攻撃は待機→溜め→打撃→待機の300ms。コードの回転や縦横伸縮で動作を代用しない。
- 開始・終了の待機は採用済み原画そのもの。スライム/コウモリのみ左右反転を使用。ゴブリンの持ち手は反転しない。

## 本編接続

`monsters-renderer.js` を `index.html` から読み込み、対象3種だけ新描画へ切替。実移動で方向/歩行を開始し、敵の近接攻撃で300msの攻撃を開始。攻撃の向きは開始時点で固定し、旧 `fl` の反転と汎用ホップを対象3種に重ねない。歩行は1歩160ms、左右の足を交互に使う。画像読み込み中・失敗時は従来絵へフォールバックする。

ゲームのターン処理・命中・ダメージ判定は既存の即時処理。今回の絵の振り下ろしフレームまで判定を遅延させる変更はしていない。プレイ感に合わせた中間コマの追加や打撃時刻との同期は今後の調整範囲。

`../preview.html` は3種同時の動作/方向/5ロケーション/実寸と拡大の比較。旧2案は待機絵の比較。`SE-walk.gif` / `SE-attack.gif` は右斜め前の再生例。`*-all-poses.png` は全方向の連絡画像。

## 生成・修正

採用済みの各方向基準絵＋その方向の4ポーズ3Dガイドを毎回参照。最初にSEを3種制作し、実画像を確認して他方向へ展開した。`generation-record.json` に全18回の参照とプロンプト、`motions.json` に原画・基準絵・ガイド・アトラスのSHA-256と位置合わせを記録。

Sのゴブリン振り上げは原画の行境界をまたいでいたため、生成し直さず切り出しを上へ拡張。N/NWの打撃は横へ振れていたため、方向別基準絵と3Dガイドで単独修正した。最初のNW修正は左手へ武器が移っていたため不採用とし、空の左腕と奥の右手を指定して再修正。修正前後と不採用原画は保持し、`correction-record.json` に記録。

登録は同一方向の4ポーズに共通倍率。動作の大きさを維持して配置する。別解像度のN/NW修正原画のみ、前傾姿勢の体高を元の歩行体高の91%へ正規化してから同じ倍率を適用する。コマ別の非等方変形や、隠れた頭だけの拡縮は行わない。これはモーション初版で、生成絵の体格差と中間コマの滑らかさは目視調整の対象。
