2026-10-23。ユーザーの「縦壁と床際の角までやって最終判断」に対応。下辺だけの試作から、上辺・左右の縦壁・内外角・孤立壁を共通ルールで構成する比較へ進めた。main・公開版は未変更。

`index.html` は本編を読み込む独立セーブの比較画面。方向別の部品と従来の汎用壁を同じ地形・位置で切替可能。確認用の部屋だけでなく通常の生成階にも使う。歩行は本編の `playerMove`・ターン・移動補間で行う。壁の除去ボタンは確認用マップ編集で、大砲のダメージ判定を再実装したものではない。

## 再利用できる規則

1. 壁を四分割し、各角で「横隣・縦隣・斜め隣」が床かを見る。4方向×8パターン＝32の基本形状。
2. 全ての部品が、マス中心・辺の中点・4マスが集まる角の位置を共有する。角の位置はそこに接する4マスの床壁から決める。同じ角を隣の壁から見ても同じ位置になる。
3. 上辺・下辺・左右で岩の肩の深さを変え、角では床側の配置に応じて輪郭を引く。上面と側面を一緒に変形し、足元も上端の70%まで寄せて垂直の切断面を避ける。
4. 内部は周囲が壁の汎用四分割部品で埋める。動的な壁除去は近傍パターンの選び直しで対応する。
5. カメラ・光・原画・ワールド単位の材質投影は前の壁キットを再利用。4位相×2材質を自動書出しするため、最終的なPNGは256枚だが、生成AIへの追加依頼は0回。

`geometry.py` が輪郭と接続点の規格、`build.py` が同じBlenderカメラ／光で書き出す工程、`runtime.js` がライブマップから選ぶ処理。原画やキャラクターは変更しない。論理的な壁マス・通路幅・視界判定・壁破壊のゲームルールは変更しない。輪郭のくぼみに見える土は追加の通行可能マスではない。

## 検証

```
blender -b -t 4 --python fushigi-wall-boundary-v1/build.py
blender -b -t 4 --python fushigi-wall-boundary-v1/verify_geometry.py
# リポジトリをHTTP配信中に
python3 fushigi-wall-boundary-v1/check.py
python3 fushigi-wall-boundary-v1/capture_walk.py
```

Blender 4.3.2、Cycles CPU、8 samples、RGBA384px、タイル128px相当、固定床ピッチ0.94。原画は既存の2枚、出自は `fushigi-wall-kit-v1/manifest.json`。`manifest.json` に原型ビルダーのハッシュと全256書出画像のハッシュ。`corner-parts.blend` は部品確認用、全形状の再構築はスクリプトを正とする。

- 実メッシュ上の共有位置30,720点を比較し、最大誤差約3e-8。256周辺地形×4位相を含む。
- 全32形状の平面変形が反転しないことを確認（最小ヤコビアン約0.041）。`geometry-validation.json`。
- ブラウザ2,048近傍描画、材質切替のゲーム状態維持、実ピクセルの遮蔽／透過、動的な壁除去、通常移動で上辺・縦壁・曲がり通路、縦画面、実セーブ分離を確認。`validation.json`。
- MVPは再確認してALL OK。初回は既存のランダム開始位置に依存する矢の着地点チェックで失敗。投擲ロジックは変更せず、前の貼り方比較と同様にテスト側の配置依存を確認してから再実行した。

歩行映像の記録にはsystem Chromium、Playwright、system ffmpegを使用。captureスクリプトは一時ディレクトリでPlaywrightへsystem ffmpegの位置を渡す。ネットワークからの追加インストールは不要。

## 目視と限界

部屋全体、上辺、縦壁、左右の曲がり際、孤立壁、別の生成階、キャラが壁に近い時、透過、歩行を確認。縦壁と角まで比較できる形に揃えた。接続端の一致だけを見た目の完成判定には使わない。

原画と位相が2マス周期のため、模様と起伏の反復はまだ見える。床・視界・照明の基準は既存の論理マスで、画像の輪郭と完全な3D空間を同一視しない。旧来の直線状の床影は、この確認用レンダラーが有効な間だけ除く。通常の古庭には作用しない。

四分割の画像合成は実時間3Dの深度描画と完全には一致せず、深い重なり・今後の高さ変更は確認が必要。確認版は全材質を先読みし、32種を4位相で保持する。採用時の配信最適化（必要材質のみ読込、アトラス化）は未実施。

この全周版を判断用の結果とし、本家の内部実装や同じ美術品質を再現したとは主張しない。採用の判断前にmainへ反映しない。
