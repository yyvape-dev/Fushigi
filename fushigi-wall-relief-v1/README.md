# 壁の部分占有と凹凸

提示されたシレン6のマス付き参考画像を設計上の参考とし、既存の独自生成素材を使って本編の壁描画を修正した。本家の内部実装が透過画像であると確認したものではない。

- 壁マスにも先に同ロケーションの床を描く。
- 隣の床マスを基準に、壁の上面から深い凹み・半円状・扇形の空間を抜く。周囲8マス、位置、階のartSeedで形が変わる。
- 側面は上面の輪郭を押し出して作り、空いた部分を四角い正面画像で塞がない。
- 床に接しない内部は全面を残す。周囲に床がある突出岩は小さく残る。遺跡は角張った切り欠き、自然系は多角形の滑らかな切り欠き。
- 凹みの基準を床の世界座標に固定し、隣り合う壁の切断位置を共有する。
- キャラを隠す手前の壁は従来の低い高さを維持。論理マップ、衝突、生成、敵・店配置、承認済みキャラ・装備は変更しない。
- 本編の描画を使う確認画面に「マス境界」を追加。橙が壁、青が歩行可能マス。見た目で床が露出していても橙のマスは壁として扱う。

確認: https://yyvape-dev.github.io/Fushigi/fushigi-dungeon-v1/random-review.html?art=wall-relief-v1

`python check.py`（ループバック8001のHTTPサーバー、Playwright/Chromium）で256地形マスク、内部全面、部分占有、共有境界、衝突データ不変、5ロケーションの実ゲーム画像、マス表示、縦画面を確認する。`validation.json` とPNGはその結果。見た目は今回の輪郭修正版であり、ロケーションごとの個別造形の作り込みは別途調整可能。
