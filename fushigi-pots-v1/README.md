# 壺19種類・足元と保存の壺の操作

2026-10-25。ユーザー依頼：本家に比べて不足する壺をまとめて追加。ただの壺・倉庫の壺は不要。足元の道具／足元の壺／複数選択／中身の直接使用も比較して実装。追加指定の剣の発光もゆったりした明滅へ変更。

## 比較元

本家は既存資料と同じ **シレン6** を対象にした。種類・用途は [GAMERS HIGH 壺一覧](https://gamers-high.com/shiren6/item/jar.html)、容量・価格は [AppMedia 壺一覧](https://appmedia.jp/shiren6/77542468)、合成時点と杖は [合成のルール](https://gamers-high.com/shiren6/system/synthesis.html)、基本の収納は [公式ガイド](https://www.spike-chunsoft.co.jp/pages/shiren6/guide/) と照合。強化+1・弱化−2、個数の増減率と上下限での破損は [検証記事](https://note.com/shiny_llama970/n/n3be3c2869353) を参照。

21種類から指定の2種類を除いた **19種類** を実装。元は保存と合成の2種類だったため、17種類を追加した。

| 種類 | 以前 | 今回 |
|---|---|---|
| 保存 | 手持ちから1個ずつ操作 | 手持ち／足元、個別・複数、内部から直接使用 |
| 合成 | 装備のみ、割る時に合成 | 投入時に合成、同種の杖も対応、合成済みでも投入枠を消費 |
| 識別 | なし | 入れた道具を識別 |
| 変化 | なし | 別の道具へ変化 |
| 換金 | なし | 実際の売値をギタン化 |
| おはらい／呪い | なし | 道具の呪いを解除／付加 |
| 強化／弱化 | なし | 階移動で装備・杖・矢・ギタンが変化 |
| 底抜け | なし | 投入品消失、破壊時に落とし穴 |
| 手封じ | なし | 手がはまり、攻撃か階移動で解除 |
| 割れない | なし | 床では割れず、生物への投擲で消失 |
| やりすごし | なし | 自分は20ターン隠れる、敵は刺激まで壺に封じる |
| 背中 | なし | HP・ちから低下・悪い状態を回復 |
| トド | なし | 前方の道具を回収 |
| 水鉄砲 | なし | 3マス・5ダメージ、炎の敵と大砲へ追加効果 |
| 笑い | なし | 正面の敵を行動不能に |
| 魔物 | なし | 残り回数分を召喚 |
| ビックリ | なし | 破壊で道具・混乱した魔物・爆発 |

## 操作の差分

- 「足元の道具→手持ちの壺」は元々あった。以前はギタンを除外していたため、今回ギタンにも対応。
- 「手持ち→足元の壺」を追加。持ち物が満杯でも壺を拾わず操作できる。
- 道具側の「壺に入れる」から、手持ち・足元の壺を選べる。
- □ボタン／Spaceで個々の道具を選択。同じ種類の2個も別々に選べる。「選択したn個」で1ターンで確定する。
- 容量不足・バッグの空き不足・古い選択・呪われた装備などは、まとめて事前検証する。失敗時は部分移動・消費・ターン経過を行わない。
- クイック使用も手持ちの保存の壺の中身を探す。保存の壺だけは中身をその場で使用・杖を振る・投げる・取り出して装備できる。保存以外の中身は閲覧のみ。復活の草は持ち物内の壺からも自動発動する。
- 店の商品は移動と効果を分けて処理。変化・消滅した商品も帳簿に残し、足元の壺へ戻すと未使用品は返品扱い。中身の使用はその商品に課金。未精算の装備は合成で消さない。
- 割れない壺の回収手段として「吸い出しの巻物」、呪われた装備の解除手段として「おはらいの巻物」も追加。

## 実装と互換性

`assets/pots.js` が種類・効果・移動トランザクション、`index.html` が使用元・所持品UI・ターン・床移動との接続。`assets/controls-ui.js` が足元の入口。

旧アイコン制作の記録は [ART_HISTORY.md](ART_HISTORY.md) と既存の原画・生成記録に保持。

セーブの版は維持。旧 `savepot:4~...` も読める。消費した投入枠・呪い・強化済みの階は、必要な場合だけ `@` メタデータを追加。倉庫と冒険途中保存の双方で保持する。壺の中へ壺を入れることは禁止。アイテム絵は既存のカテゴリ共通の壺アイコンを使う。

剣の発光周期：かまいたち6.2秒、空の刃7.2秒、火迅風魔刀6.8秒。滑らかな正弦波で変化し、既存の色・刀身・遮蔽は維持。

## 本作で決めた数値と対応範囲

種類と主要な操作・効果は本家を基準にした。一方、本家の内部乱数を再現したとは扱わない。強化／弱化の自然破損は効果発動時15%、手封じの破損は攻撃時25%を本作の初期値とした。笑いは本家資料の約8ターンに合わせた。出現階と重みも本作の短いダンジョン向け。水への特殊反応は現在登場する炎の敵・大砲に接続し、主には封じ／笑いを無効化。トドの移動は前方8マスの回収処理として表現し、専用キャラのアニメーションは追加していない。

最深階・主が残る階で落とし穴から進行制限を越えないようにする。強化／弱化は持ち物の壺に1階につき1回だけ適用し、フロアの再描画・ロードで重複しない。
