# 壁造形・床投影・遮蔽の比較（2026-10-23）

ユーザー添付のシレン6画面を直接観察して検討する。灰色の岩場「鈴なり峠」は色・形の主な参照。竹林・火山・洞窟では境界の造形が異なる。正確なカメラ角や透過の内部実装は静止画から断定しない。参照作品の画像をゲーム素材に流用していない。

## 今回の修正

前案は、明るい同じ高さの柱が柵のように並び、巨大な上面の岩と細い柱の縮尺も一致していなかった。`rejected-white-pillars.jpg` はこの不採用案の実画面。

修正版は、彩度を抑えた灰色の角張った岩群と、隙間の暗い苔を生成した。上面・側面・輪郭を一体で描いた透過岩群を、同じ縮尺で壁内部にも縁にも重ねる。4形状に決定的な縮尺・位置の変化を加える。別材質の大きな平面へ小さな柱を貼る前案は廃止。元の生成PNGは加工せず保存し、実行時にアトラスから描画する。プロンプトと原画の出自は `ridge-generation-record.json`、ハッシュは `source-art/manifest.json`。

壁床の基底と輪郭は現在のマップから描き、衝突・通路幅・視界・乱数を変更しない。キャラ、見えている道具、近くの前景壁を足元の奥行きで合成する。手前の岩はキャラの上に部分的に被る。「自然な遮蔽」「主人公付近だけ透過」「遮蔽なし」を比較できる。透過は局所的なアルファマスクであり、壁全体を薄くしない。

実際の部屋全体・入口・手前・縦画面を目視した。前案の柱列と上面の不一致は改善したが、岩群の反復と壁床の直線的な境界は今後も確認対象。

## 比較設定

通常ゲームは公開済みの低壁・床ピッチ0.82を維持。確認ページだけ `ridge`・0.94を初期選択し、実セーブを隔離する。ほかのロケーションへ適用しない。

| 案 | 造形 |
|---|---|
| 低い壁 | 共有頂点の上面・側面、立ち上がり0.24タイル幅 |
| 高い壁 | 同0.48 |
| 奥を高く手前を低く | 同0.56／0.16 |
| 岩塊 ridge | 生成された一体の岩群。旧3案の数値的な高さモデルとは異なる |

床の縦ピッチは0.72／0.82／0.90／0.94。旧3案は床投影に合わせ高さ方向も補正する。ridgeは生成画像自体が上面と側面を持つため、投影切替は床の間隔を変える比較であり、物理的な同一カメラの再現ではない。キャラ画像の縦横比は維持する。

## 検証

HTTP配信中に `python3 fushigi-overgrown-garden-v1/check_height_study.py`。同じ7×5の部屋・主人公で比較画像を生成する。16設定×256近傍地形＝4,096件の不透明な基底を確認。ゲーム状態の維持と、主人公画像の有無によるピクセル差分で前景遮蔽／透過を確認する。この接続検証だけでは輪郭の自然さや本家との一致を保証しない。

`check_browser.py` は既存3主題・縦横・保存・実セーブ分離・壁破壊・通常6階と再読込を確認する。main反映・公開はこの比較案では未実施。
