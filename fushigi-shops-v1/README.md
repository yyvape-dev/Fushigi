茶の通常店70%、藍の上級店24%、深紅の希少店6%。店自体は既存と同じ2階以降25%の出現。
HP/攻撃/守備は茶90/18/8、藍180/30/15、深紅320/45/25の初期調整。
店主が強くなり、藍は希少品が選ばれやすく、深紅のランダム枠は出現重み2以下の商品。深い階の品も段階的に扱う。回復薬・おにぎり・矢は共通。

商品は床に最大11個置く。値段表示→拾うと未精算→店主と話して購入。買うまでは所持金を減らさない。
未使用品を店内に戻せばその商品の請求を取り消す。消費・杖使用後は返品しても請求が残り、初めて使った時の全額を支払う。
矢は所有元を分けて束ね、投げた1本分だけ独立した価格を持つ。使用失敗では請求を増やさない。
自分の品は床に置いてから売却を確定。売却済みの品を再度売れない。

未精算で出口へ歩くと精算を促す。店主も出口へ移動する。
払わず持ち出す選択、店外への未精算品の投げ、ワープ、階の移動、店主への近接・投擲・杖攻撃で敵対する。
店主は通常地形に沿って追跡・攻撃。逃走後も同じ冒険中の別の店主は敵対する。
番兵・番犬は今回の次工程。初期デザインは `../fushigi-security-v1/`。現時点で出現は未実装。

冒険途中の位置・店の台帳は既存仕様同様に保存しない。未精算品を本編の持ち帰りセーブへ入れず、所有権を消して無料取得できないようにしている。既存の町の店・倉庫・銀行を維持。
