茶の通常店70%、藍の上級店24%、深紅の希少店6%。店自体は既存と同じ2階以降25%の出現。
HP/攻撃/守備は茶90/18/8、藍180/30/15、深紅320/45/25の初期調整。
店主が強くなり、藍は希少品が選ばれやすく、深紅のランダム枠は出現重み2以下の商品。深い階の品も段階的に扱う。回復薬・おにぎり・矢は共通。

商品は床に最大11個置く。値段表示→拾うと未精算→店主と話して購入。買うまでは所持金を減らさない。
未使用品を店内に戻せばその商品の請求を取り消す。消費・杖使用後は返品しても請求が残り、初めて使った時の全額を支払う。
矢は所有元を分けて束ね、投げた1本分だけ独立した価格を持つ。使用失敗では請求を増やさない。
自分の品は床に置いてから売却を確定。売却済みの品を再度売れない。

出入口ごとに担当の店主を1人配置する。通常は入口脇で待機し、未精算品を持つと各店主が自分の出口を塞ぐ。支払い・返品で脇へ戻り、通行できる。入口2つなら店主2人。
払わず持ち出す選択、店外への未精算品の投げ、ワープ、階の移動、店主への近接・投擲・ダメージを与える杖で敵対する。場所替えのみでは敵対せず、未精算で店から出た時点で盗難になる。
店主は通常地形に沿って追跡・攻撃し、複数の店主は全員で敵対する。番兵・黒い番犬が出現する。ユーザー指定により、階を移れば追跡と敵対状態は終了する。詳細は `../fushigi-security-v1/README.md`。

冒険途中の位置・店の台帳は既存仕様同様に保存しない。未精算品を本編の持ち帰りセーブへ入れず、所有権を消して無料取得できないようにしている。既存の町の店・倉庫・銀行を維持。

## 絵の制作

承認済み初期シート→元ラナマネキンのカメラ/体格と店主用の腕・脚→8方向待機→同方向の待機絵とポーズガイドを参照した歩行/右拳の攻撃。
8方向×3動作×服3色=72PNG。反転なし、倍率1.00、原点(128,224)、本編身長192基準。
元シートが同解像度なので全24ポーズで同じ倍率を使い、各靴から測定した接地点へ平行移動する。
青系の布だけ色相・彩度を替え、肌・白シャツ・髪・革・ズボンは保持。
原画・ガイド・プロンプト・ハッシュ・再現スクリプトを同梱。

```sh
blender -b -t 2 --python fushigi-shops-v1/make_guides.py
python fushigi-shops-v1/build.py
python fushigi-shops-v1/build_review.py
python fushigi-shops-v1/check_art.py
node tests/harness.js index.html tests/test_shops.js
node tests/harness.js index.html tests/test_allies.js
node tests/harness.js index.html tests/test_avenius.js
node tests/harness.js index.html tests/test_sherininya.js
node tests/harness.js index.html tests/test_mvp.js
```

40項目の店、既存の仲間36/42/43項目、本編MVP、72画像の透過/端/方向/ハッシュを確認。原画・24ポーズ・3色・ラナとの実寸を目視確認。
実ブラウザで縦390×844/横844×390/小320×640の売買・ダイアログ・入力停止・未精算・盗難・入口ごとの店主と精算後通行・追手の出現・階移動での追跡終了を確認。結果は `browser-validation.json` と `../fushigi-security-v1/browser-validation.json`。前段階の利用上限による検証停止は解消。

店舗の床は生成したワインレッドの絨毯。元原画は `source-art/carpet.png`、本編用は `assets/carpet.png`、プロンプトは番兵フォルダの `generation-prompts.json`。境界に金の縁を重ね、道具と未精算価格を読めるよう低コントラストにする。

本家の参照と採用した挙動は `../fushigi-security-v1/README.md` を参照。本編の承認済みラナ・武器12/盾10・モンスター60・仲間3人の原画と倍率は変更していない。

## 入口数の修正

壁沿いの1本の通路が何マスも店に接する場合も、連続した開口部は1つの入口として数える。外周の遠くでつながる別の入口はまとめない。部屋側の余分な接触を壁へ戻して1マスの入口へ整え、各入口に1人を配置する。商品数によって店主は増減しない。

`node tests/harness.js index.html tests/test_shop_entrances.js` で1,500生成seed・8,807部屋と再現seed13/3を検証。`python fushigi-shops-v1/check_entrances_browser.py` は入口2/3・商品数非依存・未精算封鎖・精算後通行を縦横小画面で確認する。結果と画面は `entrance-browser-validation.json` / `entrances-*.png`。

最新の56×32区画方式・L字/十字を取り込んだ後も、1,500seed・11,404部屋で連結性・入口数・隣接待機を検証。旧方式の再現例は `tests/fixtures/shop-entrances-legacy.json` に固定し、地形生成の更新と独立して再現する。
