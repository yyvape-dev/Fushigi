# 灯祭りの森：65°固定の2D完成セット

ユーザー採用：比較した2Dの木が良いため、3Dを中止し、65°固定に合う2Dアセットで仕上げる。

## 本編への反映

- 描画はCanvas 2Dのみ。three.js・3D地形・立体モデルの本編読み込みと3D設定を外した。過去の比較・実験ファイルは記録として残す。
- ダンジョンの床は縦横比 `sin(65°)` = 約0.906307787。地形・人物・道具・罠・演出は同じ投影へ揃え、町は従来どおり。
- 古いセーブの3D設定は引き継がない。ゲーム内容・預かり所・所持品・お金・冒険途中保存の形式は維持する。
- 森は採用済みの大木を使用。樹林の壁面は低い茂みへ抑え、描き込んだ木の絵を主役にする。
- 物体自身の陰影は絵に描き込み、接地影・床の暖かい光はCanvasで加える。明かりは探索済みの通れる床に限定。未探索の装飾を露出させない。

## アセット10点

配置先：`assets/dungeon/forest-fixed65-v1/`。各512×512、RGB、単色マゼンタ背景。

| キー | 用途 |
| --- | --- |
| tree | 比較で採用された大木 |
| sapling | 若木、狭い道沿いの小さな木 |
| stump | 苔むす切り株 |
| boulder | 苔岩 |
| rocks | 小石のまとまり |
| fern | シダ |
| mushrooms | 小さなキノコ |
| lantern | 吊りランタン |
| lanternpost | 根元付きのランタン支柱 |
| garland | 7個の小さな灯りを結ぶロープ |

小物9点を3×3の1枚で生成し、セルごとに切り出した。生成原画は `source-art/props-3x3.png`。描き足しは画像生成で行い、`export.py` は切り出し・縦横比を保つ縮尺・足元合わせ・背景色の正規化だけを行う。

連灯はシートの案では灯りが大きすぎたため、既に仕上げていた細い連灯 `assets/dungeon/forest-festival-v1/garland.png` を再利用した。大木は採用画像を維持し、背景色のみ厳密なマゼンタへ正規化。

元画像・プロンプトと参照条件は `generation.json`。出力の寸法・セル・足元・SHA256は `manifest.json`。`catalog.html` / `catalog.png` で10点を確認できる。

## ランダム配置

`ForestFestival.plan` はゲームの乱数や保存形式を変えず、地形座標から同じ配置を再現する。

- 木と小物は元からある壁マスに置く。大きな物を通れる床へ追加しない。
- 1マス通路に接する木は小さな若木へ切り替える。
- 階段の周り2マスは大きな装飾を除外。
- 連灯は広場の北岸に沿わせ、細い道を横切らせない。
- 小物は最大64点、連灯は最大6本、ランタンは最大12個。描画範囲と探索状況で表示対象を絞る。
- 2Dの天井処理が描き込んだ樹冠を覆わないよう、装飾は探索状態を確認したうえで霧の後へ描く。探索済みでも現在見えていない場所は薄くする。

## 再出力と確認

```sh
python fushigi-forest65-release-v1/export.py
python fushigi-forest65-release-v1/verify.py
node tests/harness.js index.html tests/test_fixed65.js
node tests/harness.js index.html tests/test_forest_festival.js
bash tests/run_all.sh
node tests/check_art.js
```

ブラウザ確認は、リポジトリルートをHTTPで8880番へ公開してから：

```sh
python fushigi-forest65-release-v1/check_browser.py
```

Playwright + Chromiumを使用。WebGLを要求すると例外を出す環境で、6ロケーション・旧3D設定の保存データ・10点の素材読み込み・未探索の非表示・縦横画面を確認する。`validation.json` に記録。撮影は元からある明るい広場の中央へ主人公を移したもので、地形や道具は追加しない。

既存回帰＋新規の固定投影・保存移行テストは全34本成功。配置検査は100 seed・広場・1マス通路・全壁で、同じ配置への復元・地形不変・階段保護・乱数の不使用を確認。
