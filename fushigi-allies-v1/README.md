# 助っ人1人目：ユズナミキ

狐耳の忍び。ユーザーの添付を基に、白〜灰の柄の着物、金の帯、紫の羽織、淡い髪、狐耳と尾、紫の狐火を簡略化した。最初の忍者服案は不採用。服装に関する追加指示を反映した着物版が今回の基準。

- [8方向・動作の確認](https://yyvape-dev.github.io/Fushigi/fushigi-allies-v1/preview.html)
- [出会い・壁越しクナイ・狐火の襲を試す](https://yyvape-dev.github.io/Fushigi/fushigi-allies-v1/game-review.html)（高HP・別セーブ）

## 出会いと同行

ダンジョン2階以降、未同行なら各階25%で出会う。開始部屋・魔物部屋・店を避け、敵・道具・罠と重ならない床へ配置。隣接して「話す」、進もうとする、または敵がいない時の攻撃で会話し、「一緒に行く」で同行。「そのまま」で保留できる。会話と加入は0ターン。

1回の冒険で同行は1人。主人公の後を通常地形に沿って追い、重なる操作は場所を入れ替える。敵や主人公と同じ床には重ならない。助っ人自身は道具を拾わず、床の罠を踏んでも発動しない。階段ではHP・レベル・経験値・状態を保ち、安全な隣接床へ移動する。体力が尽きると撤退し、その冒険では再加入しない。町へ戻る・新しく潜ると同行と成長をリセット。現在の本編は冒険途中の位置を保存しないため、助っ人も同じ保存方針。

## 強さ・成長・固定装備

初期Lvは出会った階を生成した時点の主人公と同じ。HPは26＋4×(Lv−1)。同行中の敵撃破の経験値は主人公と助っ人の両方へ1回ずつ入り、助っ人が倒した場合も主人公へ入る。成長の経験値閾値は主人公と同じで、最大Lv30、レベルアップでHP＋4。

- 攻撃＝主人公の現在の攻撃力＋2＋0.8×(本人Lv−1)を四捨五入。毒の補正を引いて最低1。
- 守備＝主人公の現在の守備力−1＋⌊(本人Lv−1)/3⌋、最低0。
- 装備はクナイ・着物で固定。装備スロットや交換処理は持たない。主人公の武器／盾の変更は次の行動から能力値へ反映するが、絵・装備名・武器の印はコピーしない。
- 「状態」メニューと同行バッジでHP・Lv・経験値・現在の攻撃／守備を確認できる。

数値は本作の初期調整。攻撃寄り、守備は少し低めの補正。

## クナイと狐火の襲

クナイは8方向の直線上、距離1〜2マスの近い敵へ攻撃。途中の壁や角を無視できるが、3マス先や直線にない敵には届かない。普通の移動は壁を抜けない。攻撃中は向きを固定した専用画像を使用する。

狐火の襲は、5マス以内に見通せる敵がいる戦闘中に12%で発動。本人だけ4ワールドターン2回行動（発動ターンを含む）。発動から12ターンは再発動しない。眠って動けないターンも持続を消費する。主人公や敵へ倍速を渡さない。主人公自身の倍速による無料の追加行動では、助っ人と敵のワールドターンは進まない。

敵は見通しがあり、主人公より助っ人が近い場合に助っ人を狙う。近接・矢・ブレス・爆発、睡眠・混乱・毒、倍速／鈍足を処理する。盗んで逃走中の敵は既存の逃走を優先する。助っ人撤退は主人公の死亡にならない。

## 画像と制作記録

3Dガイド→方向別待機→同方向基準とポーズガイドを参照した動作の順に制作。8方向はすべて個別原画で、クナイの右手・花の左側を反転しない。待機8、歩行8、攻撃8の計24ポーズ。歩行／攻撃は専用1ポーズと基準待機を交互に表示する。足元(128,224)、256px、同一の共通倍率。本編では耳を含めて登録したことによる体格差を補うため描画倍率1.25を全方向・全動作に共通適用する。原画・登録PNGは変更しない。原画の解像度差だけをシート全体で補正し、方向別の隠れた変形は使わない。

左斜め待機が右を向いて出力されたため、SW専用原画で修正した。原画・修正前の服案・待機シート・動作シート・ガイドを保存。`generation-record.json` にプロンプト・参照とハッシュを記録する。`source-art/locked-idle-reference.png` は動作生成時の基準8方向（生成時のファイル名はlocked-idle-directions.png）、`locked-idle-directions.png` は最終登録画像。

## ラナに対する大きさの補正

ユーザーの指摘で同倍率のSEを比較。ラナの不透明高さ200pxに対しユズナミキは185pxで、さらに耳の高さがその中に含まれるため人の頭・体は小さく見えた。描き直し前の説明を求められ、原画を変えず描画のみ1.25倍で補正。頭身の再生成は行わない。確認画面の「ラナと比較」または `game-review.html?size=1` で同じ床に並べて確認できる。
