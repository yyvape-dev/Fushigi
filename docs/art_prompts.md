# 絵のプロンプト集（日本語版・シレン6風の3Dフィギュア調）

置き場所：リポジトリの `assets/<キー>.png`（ゲーム内の取り込み機能は無い）。作った画像はチャットに添付すれば、Claudeが置いて反映する。
下のプロンプトは、`【画風】` の部分を先頭にコピペして使う。

## 0. 共通ルール（事実）
- 形式：PNG（JPEG/WebPも可）。正方形。キャラ・アイテムは 512×512、タイルは 256〜512 角。
- キャラ・アイテム：背景は単色マゼンタ #FF00FF（ゲーム側で自動で透明にする。判定は 赤>200 かつ 青>200 かつ 緑<90）。
- タイル（床・壁・階段・屋根など）：画面いっぱいに描く不透明の絵。背景色は不要。縦横比が違うと中央を正方形に切り出す。
- 床・壁は同じ絵が全マスに並ぶので「継ぎ目なし」で作る。
- 町は一枚絵（第7章）。

## 1. 【画風】（全プロンプトの先頭に付ける）
`3Dレンダリングのビニールフィギュア風、2頭身のデフォルメ、柔らかいスタジオ照明、なめらかで丸みのある形、ほんのり光沢、斜め上から見下ろす視点（3/4ビュー）`

## 2. 進め方（一貫性のコツ・仮説）
1. 主人公を1枚作って、気に入ったものを決める。
2. 以降は、その主人公の画像を「参照画像」として添付し、末尾に `参照画像と同じ画風・同じ照明で` を足す。
3. 1枚ずつ別々に作ると画風がズレやすい。参照画像を毎回つけるのが最短。

## 3. キャラ（背景はマゼンタ）
共通の末尾：`右向き、全身、余白をあけて中央に配置、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`

- 主人公：
  `【画風】、麦わら帽子と赤いマントの若い旅人、右向き、全身、余白をあけて中央に配置、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`
- 敵（ゴブリン）：
  `【画風】、大きなとがった耳と小さな木の棍棒を持つ緑色の小さなゴブリン、いたずらっぽい笑顔、右向き、全身、余白をあけて中央に配置、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`
- 敵を増やすとき：「緑色の小さなゴブリン」の部分だけ入れ替える（例：スライム、骸骨の兵士、コウモリ）。

## 4. アイテム（背景はマゼンタ・1個だけ中央）
共通の末尾：`1個だけ中央に配置、余白をあける、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`

- 回復薬：
  `【画風】、コルクの栓がついた、ピンク色の液体入りの丸いガラスの小瓶、1個だけ中央に配置、余白をあける、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`
- おにぎり：
  `【画風】、海苔を巻いた三角のおにぎり、1個だけ中央に配置、余白をあける、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`
- 増やすとき：名詞だけ入れ替える。

## 5. タイル（不透明・全面）
共通の末尾：`正方形の画像、画面の端から端まで全面に描く、継ぎ目なしで並べられる、枠線なし、キャラなし、文字なし`

- ダンジョンの床（立体感版）：
  `【画風】、大きく面取りされた暗い青灰色の敷石を真上から見た床、石と石の間は深く暗い溝、各石板はわずかに盛り上がり上のふちは明るく下のふちは暗い、コントラスト強め、【共通の末尾】`
- ダンジョンの壁（立体感版）：
  `【画風】、ダンジョンの高い石ブロックの壁を正面から見た絵、ごつごつと盛り上がった石レンガと深い影、いちばん上のふちに明るい石の縁、下に向かって暗くなる、コントラスト強め、【共通の末尾】`
- 階段：
  `【画風】、下へ降りる石の階段を真上から見た絵、暗い青灰色の石の床にはめ込まれている、階段の奥はあたたかい黄色い光、正方形の画像、全面に描く、キャラなし、文字なし`
- 町の地面（一枚絵を使わない場合）：
  `【画風】、短い緑の草と小さな花の地面を真上から見た絵、【共通の末尾】`
- 家の壁：`【画風】、木の梁が入った漆喰の家の壁を斜め上から見た絵、【共通の末尾】`
- 屋根：`【画風】、オレンジ色の瓦屋根を上から見た絵、【共通の末尾】`
- 倉庫の入口（door）：`【画風】、漆喰の壁にはまった木の扉、正方形の画像、全面に描く、キャラなし、文字なし`
- ダンジョンの入口（gate）：`【画風】、岩壁にあいた暗い洞窟の入口と石の階段、正方形の画像、全面に描く、キャラなし、文字なし`
- 柱：`【画風】、石の床に立つ石の柱を斜め上から見た絵、正方形の画像、全面に描く、キャラなし、文字なし`
- 木（背景はマゼンタ）：
  `【画風】、短い幹の丸くこんもりした緑の木、1個だけ中央に配置、余白をあける、背景は単色の真っ平らなマゼンタ(#FF00FF)、影なし、文字なし`

## 6. 立体感について
事実：
- ゲーム側の「設定 → 陰影（立体感）」で、壁の高さ・壁際の影・床のふち取りを足せる（なし／標準／強）。

仮説（未確認）：
- 絵そのものが「コントラスト強め・ふち取りあり」だと、立体感がより出る。のっぺりした質感だと、陰影を強くしても限界がある。

注意（仮説）：
- AIが「#FF00FFの単色」を厳密に出せず、縁にピンクのにじみが残ることがある。出たら私に伝える（透明化の許容幅を調整する）。
- 床は全マス同じ絵になる。継ぎ目が目立つ場合は、床を2〜3種に増やす対応ができる。
- 3Dフィギュア調がシレン6に近いかは、実際の画面で見て判断する。

## 7. 町の一枚絵（配置ガイド使用）
町は一枚絵にする（置き場所：`assets/town.png`）。内部の当たり判定は22×15マスの格子のまま。

手順：
1. `town_layout_guide.png`（22:15、色ブロックの下絵）と、主人公の画像を、参照画像として添付する。
   - 添付の順番：1枚目＝配置ガイド、2枚目＝主人公。
2. 下のプロンプトで生成する。
3. 配置後、設定の「町の判定を表示」をONにして、判定（赤＝歩けない／緑＝倉庫／青＝入口）と絵のズレを確認する。
4. ズレたら私に伝える（判定側を絵に合わせて調整する）。

ガイドの色の意味：
- 茶＝倉庫の屋根
- クリーム＝倉庫の壁
- 黄＝倉庫のドア
- 灰色と濃紺＝ダンジョンの入口（洞窟の石の門）
- 濃い緑の円＝木
- 外周の濃い緑＝森の縁
- 薄緑＝歩ける広場

プロンプト：
`1枚目の画像を、真上寄りの配置ガイドとして厳密に守り、そこから居心地のよいファンタジーの町の広場を描いてください。画風は、2枚目のキャラクター画像と同じ、3Dレンダリングのビニールフィギュア風、2頭身のデフォルメ、柔らかいスタジオ照明、斜め上から見下ろす視点（3/4ビュー）。ガイドの形・位置・大きさはそのまま守ること：茶色のブロックとクリーム色の壁と黄色の扉＝正面の壁に木の扉がある小さな倉庫、灰色のブロックと濃い紫の開口部＝洞窟へ続く石の門、濃い緑の円＝木、外周の濃い緑の帯＝密な森の縁、薄緑＝歩ける草の広場。広場には、ガイドにあるもの以外は何も置かず、広く空けておくこと。キャラクターなし、文字なし、UIなし、格子線なし、余計な建物なし。縦横比はガイドと同じ(22:15)、高解像度、横幅2048ピクセル以上。`

注意（仮説）：
- AIは位置を少しズラす。まず1枚作って、判定表示で確認する。
- 画像は横2000px以上が望ましい（表示サイズ「特大」で町の幅は約1760px）。

追記（事実）：
- AIは建物と木を、ガイドより約1マス上に描く傾向があった（1回目の生成）。判定側は、完成した絵を測って合わせる方式にしている。つまり、町の絵が正で、判定を後から合わせる。
- 施設を増やすときは、先にガイドへ新しい施設を足してAIに描かせ、絵ができてから判定を絵に合わせる。

## 主人公のパーツ別シート（切り絵リグ用）
元絵（全身の1枚）を参照画像として添付して使う。ぴたっと合わせるコツは「重ね順」「隠れる部分の描き足し」「基準ポーズ」を言葉で指定すること。
`添付の全身イラストと完全に同じキャラクター・画風・照明で、切り絵アニメ用のパーツ別シートを作ってください。1枚の画像に9個のパーツを、重ならないよう余白をあけて並べ、背景は透明（または単色のマゼンタ #FF00FF）。パーツ：①頭（髪とティアラ込み・首の切り口を描く）②胴（肩当て、スカート込み。首と両肩と腰は穴ではなく切り口が見える形）③マント（胴の後ろに隠れる前提）④手前の腕（キャラの右腕・画面左側の腕。まっすぐ下に垂らした基準ポーズ。肩の付け根は隠れる部分まで丸く描き足す）⑤奥の腕（キャラの左腕・画面右側の腕・獅子の肩当て付き。まっすぐ下に垂らした基準ポーズ。肩の付け根は描き足す）⑥〜⑦左右の脚（まっすぐ立った基準ポーズ。太ももの上端はスカートに隠れる分まで描き足す）。各パーツは、元の大きさの比率を保ち、基準ポーズ（直立）で、真正面寄りの同じ視点で描く。パーツ同士の重なり順は、奥の腕＜胴＜手前の腕＜頭（手前の腕を高く上げたときだけ頭より手前）。影は各パーツ内だけにし、他のパーツへの落ち影は入れない。文字なし。`
追記（仮説）：元絵が3/4視点のとき、AIは視点をそろえきれないことがある。出てきたパーツを、私が元絵に重ねて位置・大きさを合わせて調整する。

## 剣・棒・斧・盾の絵（アイテム画面と手持ちを兼ねる規約）
- ファイル名（`assets/<キー>.png`）：stick（木の棒）/ sword（鉄の剣）/ axe（大斧）/ woodshield（木の盾）/ ironshield（鉄の盾）。
- 形式：正方形・512×512、背景は単色マゼンタ #FF00FF、影なし、文字なし、1個だけ中央。

## 9. シート（アイテムの絵をまとめて作る）
- 外部AIで、**1枚に16個以内のアイテムを4列×最大4行で並べたシート**を作る。左上から右へ、上から下の順。背景は単色マゼンタ。
- できた画像をチャットに添付する → Claudeが `node tests/tools/sheets.js slice <シートID> <画像>` で切り分け（各マスの中身を自動で切り出し、256pxの正方形に収める。多少ズレていてもよい）→ `assets/<キー>.png` に置いて push。
- プロンプト：`node tests/tools/sheets.js prompt <シートID>`（Claudeが毎回チャットに本文を貼る）。シート：herb1 / herb2 / scroll / ring / weapon / shield。
- 仕上がりが悪いマスは、そのアイテムだけ8章の個別プロンプトで作り直して添付する（`assets/<キー>.png` を上書き）。
