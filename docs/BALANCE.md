# バランス調整（食料・敵の数）と計測の方法

最終更新：2026-10-22。事実（計測・調査）と仮説を分けて書く。

## 1. 計測の方法

```
node tests/harness.js index.html tests/tools/balance_sim.js
#   RUNS=回数（既定100） KIT=0|1（1=鉄の剣・木の盾・回復薬2つで出発） DUNGEON=second|first
#   ATK=敵の攻撃力の倍率  DEEP=深い階(7階〜)の敵の攻撃力の倍率  DIAG=1（ターンの内訳・死因・拾い残し）
```

- botの動き：部屋を近い順に回り（魔物部屋・店は避ける）、部屋の床の物を拾い、隣の敵は殴り、最後に階段へ行く。満腹度10%以下で食べ、HP30%以下で回復薬か草を使う。強い武器・盾を拾えば付け替える。
- 巻物・杖・腕輪・投げる・逃げるは使わない。そのため**戦闘の死亡率は人が遊ぶより高く出る**（仮説）。食料の収支（拾う量と使う量）は人に近い。
- 調整を変えたら、前後をこの表で比べる。

## 2. 本家（シレン6）の数値（調査した事実）

| 項目 | 本家 | 出典 |
|---|---|---|
| 満腹度の減り方 | 10ターンで1（ハラモチの盾で20ターン）。0になると毎ターンHP-1 | gamers-high、EZ版シレンGold wiki |
| 最大満腹度の上限 | 200 | gamers-high |
| おにぎり | 満腹度+50、満腹時に食べると最大+3 | とぐろ島探検録Wiki「食料」 |
| 大きいおにぎり | +100、最大+4 | 同上 |
| 腐ったおにぎり | +30、5ダメージ＋悪い効果1つ（ちから低下・混乱・睡眠・目つぶし・まどわし） | 同上 |
| 敵の湧き | 一定ターンごと（風来街道で30ターン、神髄で40ターン） | feketerigo「いろいろな仕様」 |
| 1階の生物の上限 | 36〜38体 | 同上、EZ版wiki |

- **パンは本家シレンには無い**（パンはトルネコの大冒険などのシリーズ）。名前はユーザー指定の4種、効果はシレン6のおにぎり系に合わせた。「小さなパン」の値（+25）は独自。
- 本家の「1階の最初の敵の数」「アイテムの数」「食料の出る割合」は公開情報で見つからなかった。

## 3. この調整で変えたこと

| 項目 | 前 | 後 |
|---|---|---|
| 食料 | おにぎり1種（出る割合5.4%） | パン4種：小さなパン+25（最大+1）／パン+50（+3）／大きなパン+100（+4、2階から）／カビの生えたパン+30・5ダメージ・悪い状態。合わせて約13%（1階は種類が少ないので約27%） |
| 満腹で食べる | 食べられない | 最大満腹度が上がる（上限200%） |
| 最初の敵 | 1階4体〜（最大14体） | 1階3体〜12階7体（広い階は増える、最大10体） |
| 時間で湧く敵 | なし（魔物呼びの腕輪だけ） | 30ターンごとに、見えていない部屋に1体（16体まで） |
| 敵の攻撃力 | — | 調整用の値 `ENEMY_BAL` を追加（**今は1倍＝変更なし**） |

- 古いセーブの「おにぎり」は「パン」に読み替える。
- 絵：`assets/bread_small.png` などを置けば自動で使う。無い間はドット絵の仮表示。食べる動作の手持ち絵は `assets/bread.png` が無ければおにぎりの絵。

## 4. 計測結果（ふかい洞窟12階、各120回、鉄の剣・木の盾・回復薬2つで出発）

| | 調整前 | 調整後 |
|---|---|---|
| 死因：空腹 | 80 / 120（67%） | 13 / 120（11%） |
| 死因：戦闘 | 40 | 106 |
| 1階あたりのターン | 236〜677 | 200〜240 |
| 1階あたりの満腹度の消費 | 24〜65% | 20〜25% |
| 1階あたりの食料（床） | 0.3〜0.7個（平均約15%分） | 0.6〜1.0個（約28〜33%分） |
| 7階の到達 | 13% | 75% |
| 10階の到達 | 1% | 19% |
| 踏破 | 0% | 1% |

- 注意：調整前の数字には、botの不具合（持ち物がいっぱいで捨てる・拾うを繰り返す、仲間の勧誘で止まる）で待ちのターンが半分ほど含まれていた。調整後はbotを直してから測った。前後の差の一部はbotの修正による。
- 手ぶらで出発：空腹 24・戦闘 95、10階到達 17%。

## 5. 未調整・次の判断材料

- 深い階（8階〜）の戦闘での死が多い（1階あたり40〜80%）。死因の上位は ねむりダケ系（眠らされて囲まれる）、ゴブリン・オーガ・スケルトン系。敵の攻撃力を7階以降0.85倍・0.75倍にしても死亡率はほぼ変わらなかった（事実）。
- botは巻物・杖を使わないので、敵を弱めるかは**実機で遊んだ感触で決める**（仮説：人なら識別・巻物でかなり楽になる）。
- 候補：ねむりダケ系の眠り時間、深い階の敵の出る割合、レベルアップ時のHP（今は+4）。

## 6. 敵の出現表・深層の敵・30階のダンジョン（2026-10-23）

**事実（シレン6の仕様）**：敵は階ごとの出現表（その階に出る敵の一覧と重み）から選ばれる。種類数の目安は 序盤4〜5・中盤7〜9・深層9〜12（風来街道）。深層の敵は数字の強さより能力が特徴（魔法の弾で転移・混乱・封印・レベルダウン／鈴で仲間を呼ぶ／アイテムに化ける／雷／大砲／忍者）。

**この実装**（`assets/enemy-table.js`）：系統ごとに「出る段階の範囲」を書き、階ごとの一覧を作る。ダンジョンごとに 段階＝階×`stageK`（はじまり1／ふかい1.25／そこなし1）。強いランクは早く出さない（ランク2は段階4〜、3は8〜、4は12〜）。

| 段階 | 1 | 5 | 10 | 15 | 20 | 30 |
|---|---|---|---|---|---|---|
| 種類数 | 3 | 7 | 12 | 14 | 11 | 9 |

- 深層の新6系統（各4ランク＝24種）：ニンジャ（14〜・素早く手裏剣）／まじゅつ師（14〜・魔弾：転移→混乱→くちなし→レベルダウンの順にランクで変わる）／ミミック（15〜・アイテムに化けて隣に来ると襲う）／すず坊主（16〜・鈴で1〜3体呼ぶ。呼ばれた敵は経験値半分）／いかずち岩（18〜・殴ると同じ部屋に雷）／おおづつ兵（20〜・動かず射程8の大砲、2ターンに1発）。
- 30階の「そこなしの洞窟」：ふかい洞窟を踏破すると解放。30階に主「アビスロード」（HP320・炎）と取り巻き。倒すまで階段が使えない。
- 同時に出る種類数が段階15で14と、本家の目安（最大12）よりやや多い（仮説：問題ないが、遊んで多すぎるなら減らす）。

**計測（そこなしの洞窟、各20回。スモークのみ）**
- 事実：踏破0%。到達率は 7階 45〜60%・10階 25%・12階 5〜20%。14階以降へ進んだのは手ぶら出発の1回だけ。死因は戦闘（18/20）。
- 比較（ふかい洞窟12階・旧仕様、120回）：7階 75%・10階 19%。ほぼ同程度。
- 事実：botは巻物・杖を使わず、深い階までほぼ届かない。**深層の敵（14階〜）の難しさはbotでは測れていない**。
- 仮説：深層は人が遊んで判断するのが早い。強すぎ・弱すぎ・理不尽（レベルダウン、ミミックの不意打ち）の感触を教えてほしい。
- ふかい洞窟（12階）は段階が最大15になり、まじゅつ師・ミミックが最後の数階で出始める。旧仕様より難しい可能性（未計測）。
