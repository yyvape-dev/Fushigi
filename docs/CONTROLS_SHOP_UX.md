# 移動・メニュー・店と敵の次工程

2026-10-21。PR #7の本番採用後のユーザー希望。ここは次工程の作業方針で、実装済み仕様ではない。

## 参照

[シレン6公式・基本操作](https://www.spike-chunsoft.co.jp/pages/shiren6/guide/)：8方向移動、方向だけの変更、斜め移動固定、ダッシュ、ダッシュで道具の上へ乗る、足踏み。タッチ・キーボードにはFushigi用の割当で翻案する。公式のボタン配置をそのままブラウザへ当てはめない。

## 進め方

1. 移動：通常歩行とダッシュを区別。その場の方向変更はターンを消費しない。斜め固定で誤入力を防ぐ。連続移動は敵・道具・罠・階段・分岐で止め、操作解除／メニューで確実に停止。ダッシュ中の商品・道具の上に乗る動作と自動拾いを区別する。
2. UI：メニューの入口、持ち物、足元、状態、地図、履歴、設定を一貫した決定／戻るで接続。店・倉庫も持ち物と同じ一覧＋説明＋操作。選択中のターン停止、操作先、タッチの押しやすさを維持。
3. 店：現行は部屋内から売買メニューを開く方式。商品配置・価格確認・店主・購入と売却・会計の流れを具体化する。未購入品の所有者／代金の記録を明示し、通常の拾い物と混ぜない。商品の使用・投擲・店外移動の扱いも含めて設計する。泥棒・店主敵対は未実装であり、対応したと表記しない。
4. 敵：採用済み3種を正とし、次は役割が重ならない遠距離・状態異常・防御型を候補にする。候補の基準絵から確認し、8方向と歩行／攻撃へ展開。人型・獣は悪意ある簡潔な顔、無髪ゴブリンの維持。反転は対称な敵に限る。

移動・UI・店の操作を先に揃え、その後に敵を増やす想定。優先順はユーザー回答で更新する。
