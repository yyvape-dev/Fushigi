# 引き継ぎ資料（Fushigi：シレン風・個人用）

最終更新：2026-10-20 ／ 直近：アイテム大拡充（草21・巻物16・腕輪17・武器15・盾12）と状態異常（シレン6準拠）。その前：戦闘の演出（斬撃の弧・火花・画面の揺れ）

## 1. 結論（いまの状態）
- 遊べる：町→洞窟5階（`はじまりの洞窟`）→踏破→町。敵5種・武器3種・盾2種・アイテム多数・倉庫・セーブあり。
- 見た目：主人公は**パーツ式の切り絵アニメ**（歩き・攻撃・装備・被ダメ/死亡の表情）。**敵とアイテムは仮絵**（ゴブリンの色違い等）。ここが最大の見た目の穴。
- 戦闘の演出：命中で斬撃の弧＋火花、撃破は大きめ、被弾は赤い斬撃＋画面の揺れ（世界だけ揺れ、地図・HUDは揺れない）。設定「戦闘の演出」で なし/標準/強（保存される。酔うときは「なし」）。絵は不使用（canvasのコード描画）。**実機での見え方・強さは未確認**。
- アイテム（2026-10-20）：本家シレン6の草・巻物・腕輪・武器・盾を、このゲームの規模（最大HP20）に数値を縮めて追加。`ITEMS` に1項目足すだけの設計は維持（`from`=出始める階、`seal`=武器盾の印、`equip:'ring'`=腕輪）。
  - 状態異常：プレイヤーは `player.st`（混乱・睡眠・目つぶし・くちなし・ちから低下／倍速・パワーアップ・無敵・よく見え）、敵は `e.st`（confuse・sleep・boost）。HUD左上に残りターン、敵の頭上に Zzz／？／≫。
  - 腕輪は2枠（`eqRings`）。同じ腕輪を2つで効果2倍。判定は `ringN('名前')`。武器盾の印は `wSeal()` / `sSeal()` で判定（`hitEnemy`→`strikeOne`、`enemyTurn` に処理がある）。
  - 復活の草：持っているだけで、力尽きたとき自動復活（`checkDeath`）。草は雑草になる。
  - 変更した挙動：潜るたびに最大HPを20へリセット（本家どおり）／草は満タンで食べると最大HPが上がる／強化の巻物→「天の恵みの巻物」（武器のみ。たまに+3）と「地の恵みの巻物」（盾）に分離／階に出るアイテムは2〜5個で、`from` 以降の階で出る。
  - 見送り（システムが無い）：識別・呪い・おはらい・メッキ・印・合成、罠関連（罠消し・めぐすり草の本来の効果）、投げる系（連射・遠投の腕輪など）、ちから／レベル（しあわせ草など）、お金（バクチ・値切り）、水・壁抜け。ちからの草/腕輪は攻撃力で代用。
  - 確認用：設定の「お試しアイテム → 配る」で、まだ無い種類を倉庫へ1個ずつ入れられる（倉庫の上限60まで。何度でも押せる）。
  - **絵の入れ方（2026-10-20に一本化）**：ゲーム内の画像取り込み（設定の「素材」「シート取り込み」・IndexedDB）は**削除した**（端末ごとに絵が食い違い、ゲームのコンセプトにも合わないため）。絵はリポジトリの `assets/<キー>.png` だけ（https のとき自動で読む）。ユーザーはスマホなので、**チャットにAI画像を添付→Claudeが `node tests/tools/sheets.js slice <シートID> <画像>` で切り分けて `assets/` に置き、push**する。プロンプトは `node tests/tools/sheets.js prompt <シートID>`、**毎回チャットに本文を貼る**（ユーザーの明言。mdに入れるだけは不可）。シート6枚：herb1/herb2/scroll/ring/weapon/shield（`list`で一覧）。切り分け後は256pxに縮小（起動時に約100枚読むため軽くする）。
  - 数値は本家の値の縮小版（**仮説**。遊んで調整する）。本家の数値は攻略サイト（appmedia）の一覧に基づく。
- 画面：**横持ちに対応**（自動で1マス64px、横約13マス）。上部に本家風のHP/満腹度バー。
- 公開：https://yyvape-dev.github.io/Fushigi/ （リポジトリ `yyvape-dev/Fushigi` の main を push すると反映）。
- 方針：動くものを先に、遊んで気づいたことを1つずつ足す。**ビジュアルの没入感は面白さの核**（ユーザー明言）。休止して先にプレイテスト、は却下済み。

## 2. 構成と動かし方
| もの | 場所 |
|---|---|
| ゲーム本体（HTML/CSS/JS 1ファイル、約1600行） | `index.html` |
| 絵（https のときのみ自動読込） | `assets/<キー>.png`、主人公パーツ `assets/rig/*.png`、町 `assets/town.png` |
| 絵のプロンプト集 | `docs/art_prompts.md`（キャラ・アイテム・敵4種・武器盾・パーツシート） |
| 自動テスト | `tests/harness.js` + `tests/test_mvp.js` |
| 実ブラウザの画面確認 | `tests/tools/shot_playwright.py` |

- テスト：`npm i @napi-rs/canvas` → `node tests/harness.js index.html tests/test_mvp.js` → **`ALL OK`** が出れば成功（画面なしで描画・ボット走破まで確認）。
- 主要な設定値（`index.html` 内）：タイル種 `WALL..PILLAR`、ダンジョン `DUNGEONS.first`（floors:5）、`ENEMIES`、`ITEMS`、`RIG`（切り絵の支点・倍率）、`CHAR_K=[1,1.3,1.5,1.8,2.1]`。
- 保存：localStorage（URLごと）。絵は `assets/` のみ（ゲーム内取り込みは無い）。主人公は設定の「主人公の表示」で パーツ/1枚絵（`assets/player.png`）を切替。
