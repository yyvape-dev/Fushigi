# 引き継ぎ資料（Fushigi：シレン風・個人用）

## 1. 結論（いまの状態）

- **視界・地図・加入前の仲間（2026-10-22）**：部屋の床形状を一枚のマスクにまとめ、縮小マスクを3回ぼかす照明へ変更。Canvas.filter未対応のスマホでも境界をぼかす。L字・十字の形状と敵の可視判定は維持。地図の床アイテムは青、敵は赤。加入前の仲間3人も1世界ターンに1歩徘徊し、主人公に隣接すると会話用に待つ。加入するまでは攻撃・特殊能力・敵からの標的化なし。加入後の追従・戦闘は従来どおり。

- **遊べる範囲**：町 → 洞窟（はじまりの洞窟5階／ふかい洞窟12階。後者は1回踏破で解放。設定「行き先」で切替）→ 踏破 → 町。倉庫・預金・セーブあり。
- **段階1〜3は実装済み、実機の合格基準は未確認**（`docs/ROADMAP.md`）：レベル・ちから・敵60種（15系統×4ランク）・罠6種・魔物部屋・識別・お金・店・投擲・状態異常・アイテム多数。
- **見た目はほぼ置き換え済み**：主人公・武器12種・盾10種・敵60種・助っ人3人・店主・番兵・番犬は専用のコマ絵（8方向）。5ロケーション（樹林・鍾乳洞・風化遺跡・氷晶洞・火山洞）の地形画像。BGM・SE。
- **ダンジョン生成（2026-10-22）**：区画方式の地形、56×32、L字・十字の部屋、階段は歩く距離で配置。詳細・計測は [DUNGEON_GENERATION.md](DUNGEON_GENERATION.md)。
- **公開**：https://yyvape-dev.github.io/Fushigi/ （`yyvape-dev/Fushigi` の main が反映される）。
- **運用**：コードはCodex（実装・画像制作）とClaude（仕様判断・地形生成・レビュー）が共用。変更はブランチ → PR → マージ。Claudeの環境は、レビューなしのマージを自動で止める。ユーザーが明示すればマージできる。
- **方針**：動くものを先に、遊んで気づいたことを1つずつ足す。ビジュアルの没入感は面白さの核（ユーザー明言）。

## 3. 実装済みの要点

- **戦闘**：レベル（Lv1〜30、潜るたびにリセット）、ちから（8基準）、ダメージ＝(攻撃力−守備＋1)×87.5〜112.5%（本家式の簡略版＝仮説）、命中92%、斬撃・火花・画面の揺れ。
- **敵**：60種（通常）＋店の番兵・番犬（`security`）。分裂・盗み・飛行・壁抜けなどの個性。階ごとに強い上位種へ置換。敵数は部屋数に応じて増え、最大14体。
- **罠・魔物部屋・識別**：罠6種、魔物部屋（2階から約20%）、草・種・巻物・腕輪・杖は潜るたびに仮名（使うと判明）。
- **店**：町の店（倉庫の窓口）と、2階から約25%のダンジョン内の店部屋。店主は出入口に立ち、未精算で出ようとすると塞ぐ。盗むと番兵・番犬が追う。次の階へ追跡は持ち越さない。
- **助っ人**：2階以降25%で遭遇、同行は1人まで、冒険ごとにリセット。
- **操作・UI**：8方向の円形操作盤、0ターンの向き変更・ダッシュ、両手／右手／左手の配置、横持ち対応、液体宝石のHP・満腹度バー。
- **地形**：区画方式（chain／branch／loop）、L字・十字の部屋、5ロケーションの画像、壁の部分占有の描画。階段は歩く距離で最遠の7割以上の部屋から選ぶ。開始地点から歩いて8マス未満には敵を置かない。

## 6. 注意点（過去のつまずき）

- **作業前**：`CLAUDE.md` / `AGENTS.md` を読む。変更後は上のテストで `ALL OK` を確認してから push。作業を終えたら、この資料の「現状」「次にやること」を更新する。
- **生成を変えるとき**：`rooms[]` は長方形の外枠（`x,y,w,h,cx,cy,role,shape`）。中心（階段・店の位置）は必ず床。出入口・店番の配置・魔物部屋・店は `rooms` と `roomGrid` に依存する。
- **乱数**：地形は `Math.random()` で得たシードから作るが、敵・アイテム・罠は別の乱数。階全体の再現はまだできない。
- 腕の呼び名：手前の腕＝キャラの右腕＝画面左／奥の腕＝キャラの左腕＝画面右（プロンプトもこの表記）。
- 外部サイト（参考画像のURLなど）は、この作業環境から403で取得できない。画像はチャットに添付してもらう。
- 絵の入れ方：ゲーム内の取り込み機能は無い。`assets/<キー>.png` を置く（https のときのみ自動読込）。シートの切り出しは `node tests/tools/sheets.js`。
- スマホ運用のため、**絵のプロンプトは毎回チャットに本文を貼る**（ユーザー明言）。
- 木の棒・大斧（旧画像、512px高）は、承認済み武器（256px高）と同じ0.66倍で描くと約2倍に見える。`assets/approved-hero.js` の旧装備分岐で `0.66*256/画像高` に補正済み（握り位置は元画像の座標のまま）。旧PR #9は競合したため、同じ修正を最新mainへ入れ直した。
