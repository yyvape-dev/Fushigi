## 3. 実装済みの要点

- **戦闘**：レベル（Lv1〜30、潜るたびにリセット）、ちから（8基準）、ダメージ＝(攻撃力−守備＋1)×87.5〜112.5%（本家式の簡略版＝仮説）、命中92%、斬撃・火花・画面の揺れ。
- **敵**：84種（通常）＋主＋店の番兵・番犬（`security`）。分裂・盗み・飛行・壁抜け・魔弾・召喚・化け・雷・大砲などの個性。出現は階ごとの出現表（`enemy-table.js`）。敵数は部屋数に応じて増え、最大14体。
- **罠・魔物部屋・識別**：罠6種、魔物部屋（2階から約20%）、草・種・巻物・腕輪・杖は潜るたびに仮名（使うと判明）。

## 6. 注意点（過去のつまずき）

- **作業前**：`CLAUDE.md` / `AGENTS.md` を読む。変更後は上のテストで `ALL OK` を確認してから push。作業を終えたら、この資料の「現状」「次にやること」を更新する。
- **生成を変えるとき**：`rooms[]` は長方形の外枠（`x,y,w,h,cx,cy,role,shape`）。中心（階段・店の位置）は必ず床。出入口・店番の配置・魔物部屋・店は `rooms` と `roomGrid` に依存する。
- **冒険の保存に足し忘れると**：再読み込みでその値だけ消える。モジュールの `state` に冒険中の値を足したら run-save にも足すこと。
- **乱数**：地形は `Math.random()` で得たシードから作るが、敵・アイテム・罠は別の乱数。階全体の再現はまだできない。
- 腕の呼び名：手前の腕＝キャラの右腕＝画面左／奥の腕＝キャラの左腕＝画面右（プロンプトもこの表記）。
- 外部サイト（参考画像のURLなど）は、この作業環境から403で取得できない。画像はチャットに添付してもらう。
- 絵の入れ方：ゲーム内の取り込み機能は無い。`assets/<キー>.png` を置く（https のときのみ自動読込）。シートの切り出しは `node tests/tools/sheets.js`。
- スマホ運用のため、**絵のプロンプトは毎回チャットに本文を貼る**（ユーザー明言）。
- 木の棒・大斧（旧画像、512px高）は、承認済み武器（256px高）と同じ0.66倍で描くと約2倍に見える。`assets/approved-hero.js` の旧装備分岐で `0.66*256/画像高` に補正済み（握り位置は元画像の座標のまま）。旧PR #9は競合したため、同じ修正を最新mainへ入れ直した。
