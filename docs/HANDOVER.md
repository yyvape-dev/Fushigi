## 1. 結論（いまの状態）
- 遊べる：町→洞窟5階（`はじまりの洞窟`）→踏破→町。敵5種・武器3種・盾2種・アイテム多数・倉庫・セーブあり。
- 見た目：主人公は**パーツ式の切り絵アニメ**（歩き・攻撃・装備・被ダメ/死亡の表情）。**敵とアイテムは仮絵**（ゴブリンの色違い等）。ここが最大の見た目の穴。
- 戦闘の演出：命中で斬撃の弧＋火花、撃破は大きめ、被弾は赤い斬撃＋画面の揺れ（世界だけ揺れ、地図・HUDは揺れない）。設定「戦闘の演出」で なし/標準/強（保存される。酔うときは「なし」）。絵は不使用（canvasのコード描画）。**実機での見え方・強さは未確認**。
- アイテム（2026-10-20）：本家シレン6の草・巻物・腕輪・武器・盾を、このゲームの規模（最大HP20）に数値を縮めて追加。`ITEMS` に1項目足すだけの設計は維持（`from`=出始める階、`seal`=武器盾の印、`equip:'ring'`=腕輪）。
  - 状態異常：プレイヤーは `player.st`（混乱・睡眠・目つぶし・くちなし・ちから低下／倍速・パワーアップ・無敵・よく見え）、敵は `e.st`（confuse・sleep・boost）。HUD左上に残りターン、敵の頭上に Zzz／？／≫。
  - 腕輪は2枠（`eqRings`）。同じ腕輪を2つで効果2倍。判定は `ringN('名前')`。武器盾の印は `wSeal()` / `sSeal()` で判定（`hitEnemy`→`strikeOne`、`enemyTurn` に処理がある）。
  - 復活の草：持っているだけで、力尽きたとき自動復活（`checkDeath`）。草は雑草になる。
  - 変更した挙動：潜るたびに最大HPを20へリセット（本家どおり）／草は満タンで食べると最大HPが上がる／強化の巻物→「天の恵みの巻物」（武器のみ。たまに+3）と「地の恵みの巻物」（盾）に分離／階に出るアイテムは2〜5個で、`from` 以降の階で出る。
  - 見送り（システムが無い）：識別・呪い・おはらい・メッキ・印・合成、罠関連（罠消し・めぐすり草の本来の効果）、投げる系（連射・遠投の腕輪など）、ちから／レベル（しあわせ草など）、お金（バクチ・値切り）、水・壁抜け。ちからの草/腕輪は攻撃力で代用。
  - 確認用：設定の「お試しアイテム → 配る」で、まだ無い種類を倉庫へ1個ずつ入れられる（倉庫の上限60まで。何度でも押せる）。
  - **絵の方針（2026-10-20決定）**：後で未識別システムを入れるため、**床・持ち物は カテゴリで1種類固定**（`ICON_BY_CAT`：草`icon_herb`・種`icon_seed`・巻物`icon_scroll`・腕輪`icon_ring`・杖`icon_staff`・武器`icon_sword`・盾`icon_shield`。`iconOf()` が解決、無ければ個別キー→文字表示）。薬`potion`・食`onigiri`は個別。**武器・盾だけ、装備時の手持ち絵が個別**（キー＝アイテムのキー。`extName` が末尾の数字を削るので、キーの末尾に数字を付けない。`ironshield2`→`tekkoshield`に改名済み）。持ち物・倉庫の行にも絵が出る（`iconUrl`）。
  - 取り込み済み：icon_herb / icon_seed / icon_staff / icon_scroll / icon_ring / icon_sword / icon_shield / potion / onigiri（落ちものは完了）。**未作成**：武器12・盾10の手持ち絵（シート `icons` / `weapon` / `shield`）。

## 3.5 主人公リグの問題と方針（2026-10-20 ユーザー指摘）
- **事実（描画して確認）**：腕は胴の横に浮いた短い棒で、肩の付け根が胴の外に出る（肩の出っ張り）。歩きは脚・腕が関節なしの棒で根元から回るだけ。肘・膝・胴のひねりが無く、人体の動きに見えない。向きは斜め前の1方向のみ（向き別の描画はコードに見当たらない）。
- **ユーザーの指摘**：「動いているから良し」ではなく質の問題。手持ち武器も、向きが固定という前提でしか2D回転で足りない（上・下・横向きは別の絵が要る）。→ 私の「3D不要」は撤回済み。
- **方針（仮説・試行中）**：パーツ式の切り絵をやめ、**3Dマネキン等の骨組み → 外部AI → 向き別・動作別のコマ絵**にする案（奈落の流れ：`naraku-mannequin` → 外部AI → `naraku-sprite`）。ユーザーが**まずChatGPTに骨組みから生成まで一度やらせて**可否を見る。結果が来たら、向き（4方向 or 左右反転で3方向）×動作（待機・歩き・攻撃・被弾・死亡）のコマ数と、`drawChar` への差し込み方を決める。
- 代案（未採用）：A 肩の支点だけ調整／B 腕・脚に関節を足して7→約11パーツに。いまの `rigguide.js` の分解図（`node tests/tools/rigguide.js 出力.png`）は B や敵キャラ用。
- 武器12種の手持ち絵は取り込み済み（`assets/<キー>.png`、握り＝画像の下から20%）。向き別が必要になれば作り直す前提。盾10種（シート `shield`）は未作成。
