# 主人公の方向別スタート絵：ゲームへの組み込み基準 v1

目的はFushigiのゲーム内表示に合う共通スタート絵を固定すること。アニメーション作成はこの基準が定まってから行う。

## 共通座標

- 1コマ256×256 RGBA。方向順は S / SW / W / NW / N / NE / E / SE。
- 足元の基準点は全方向(128,224)。頭頂の目標はy=32。頭頂から接地基準まで192px。
- ゲームでは頭頂〜接地基準を `TS * CHAR_K[charPref]` で描く。初期設定×1.5では1.5マス。
- 256px画像のゲーム内拡大率は `TS * CHAR_K[charPref] / 192`。
- 足元をタイルの中心寄りの `(tileX+TS/2, tileY+TS*.9)` に置く。既存の影と位置を合わせる。
- カメラは平行投影、上から約26度。8方向で同じ高さ・縮尺・待機姿勢。左右反転は使わない。
- 画像の四角い枠を1.5マスにするのではなく、頭頂から足元までを1.5マスにする。

## スタート姿勢

両足接地、左右に重心を偏らせず、腕は軽く曲げて腰の横。両手は空の握り手。
金髪の髪型、左側の髪飾り、大きな左肩当て、赤い短いマント、鎧の構造を全方向で保つ。
武器・盾は基準絵に描き込まない。手と体の間に装備の取り付け余地を作る。

## 将来の装備描画

- キャラクター本人の右手＝武器、本人の左手＝盾。画面左右とは区別する。
- 各方向に手の位置、装備の角度、手前／奥の描画順を記録する。
- 共通描画順は「奥の装備 → 本体 → 手前の装備 → 武器の握り手の前景マスク」。
- 盾は面の向きが変わる。1枚絵の左右反転や縮小だけで全方向の完成表示を代用しない。
- 武器の柄の位置と盾の持ち位置を装備画像側にも記録する。描画時に手の座標と一致させる。
- 装備の検証に使う記号画像は、本番アートとは区別する。
- 今回の手の座標・マスクは待機1コマのもの。歩行・攻撃ではコマごとに追加し、奥行きが変わる瞬間の描画順も更新する。
- 両手持ち、大盾、長柄武器などは同じ待機姿勢で収まるとは限らない。必要なら装備カテゴリ別の姿勢を設ける。

## 合格確認

方向だけ切り替えても足元が動かず、身長が跳ねないこと。SとN、WとEが別の絵になっていること。
設定の小・標準・大で床と体の大きさを確認し、町と洞窟で浮かないこと。
武器と盾を別々に表示し、右手と左手の取り違え、手からの浮き、遠い手側の装備が体を貫通する表示がないこと。
この基準を確認するまでは、歩行・攻撃の量産に進まない。
