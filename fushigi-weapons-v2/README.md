# 武器デザイン本番改訂・刀身の発光

2026-10-25。全体を重厚にする依頼に対し、12武器の厚塗り・金属・革・古金の意匠を改訂。妖刀かまいたち・空の刃・火迅風魔刀は個別の採用原画を使用。

- 妖刀かまいたち：ユーザー提供の角張った特殊な日本刀を形状参考に、赤黒の刀身と深紅の柄を制作。曲刀・鎌状の初案から変更。個別原画はユーザー採用済み。
- 空の刃：採用かまいたちを画風参考に、青鋼・段差・根元の透かし・銀の鍔へ変更。個別原画はユーザー採用済み。
- 火迅風魔刀：赤黒の地鉄、金の梵字風の装飾的象嵌、唐草の金工と透かし鍔。個別原画はユーザー採用済み。
- 他9種：重厚化した12種シートから切り出し。連撃刀は二股を廃止して二筋の溝を持つ一枚刃へ。

## 本番仕様

`items/` は512×512・単色マゼンタ背景の単体PNG。`assets/` は既存装備用の192×256 RGBA。握り(96,210)、先端から握り175px、描画倍率0.66。縦横比を維持。承認済み `fushigi-equipment-v3/` の原画・レンダラー・握りソケット・盾の倍率0.59・NW/SEの重なりは変更しない。

`assets/approved-hero.js` が新カタログを読み込む。アイテムキーと所持品のデータは維持。`weapon-glow.js` は3種の刀身マスクだけを着色し、赤／青／暗い外縁と赤の脈動をコードで作る。装備用のキャンバスを既存レンダラーへ渡すため、回転・短縮・手による遮蔽・前後順が待機、攻撃、歩行にそのまま適用される。柄と手は発光しない。炎の静止画や浮遊エフェクトは原画へ追加していない。

発光画像は武器ごとに共有し、約30fpsで更新。Canvasの生成やピクセル読出しはゲームの描画ループで行わない。画面非表示・死亡・メニュー中は発光目的の連続描画を止める。動きを減らす設定では一定の明るさにする。

## 制作記録・再現

標準の画像生成ツールで作成。`source-art/catalog.png` は既存12種一覧とv3の銀の剣を参照。`source-art/kamaitachi.png` はユーザー添付を参照。`source-art/skyblade.png` は採用かまいたちを参照。`source-art/firesword.png` は採用かまいたちと空の刃を参照。個別原画は1254×1254、シートは1182×1330。画像を再生成せず、採用原画から背景除去・等比縮小・握り位置合わせだけを機械的に実施。

元の依頼指定は「全体を重厚」「かまいたち・連撃刀は形から見直し」「描き込まれた炎は停止画に見えるため廃止」。かまいたちは赤黒の角張った特殊な日本刀、空の刃は同系統の青で形を変更、火迅風魔刀は赤黒・刀身に梵字・絢爛な装飾の日本刀。最終指定は「本番デザインに落とし込み、各々赤・青・赤黒とコードで発光」。生成物の個別ファイルのSHA-256、切出し範囲、握り位置は `weapons.json` に保存。

再現：リポジトリルートで `python fushigi-weapons-v2/build.py`。Pillow・NumPyが必要。

確認：`python -m http.server 8000` で配信し、`http://localhost:8000/fushigi-weapons-v2/preview.html`。3本を同時表示し、12武器の全8方向と待機・歩行・攻撃を切り替える。発光なしとの比較、一時停止に対応。ブラウザ検証・スクリーンショットと検証結果は同フォルダに保存。

数値検証：`node fushigi-weapons-v2/check-glow.cjs`、`node tests/check_art.js`、`bash tests/run_all.sh`。発光の時間変化、元画像の不変、柄領域の不変、端の欠け、動きを減らす設定を検証。方向別原画は追加せず、既存の装備レンダリングを使用。

## 検証結果

- 本番のローダーを使用し、12武器×8方向×6コマ=576描画、発光3本×8方向×4歩行コマ=96描画。ブラウザ例外なし。攻撃576描画で空画像・出力端の欠けなし。
- 本編で新カタログ12種・かまいたちの装備・発光用の継続描画を確認。390×844の実画面は `game-mobile.png`。
- 確認画面は390×844・844×390・320×640で横にはみ出さない。動きを減らす設定で発光用の継続描画を停止する。
- `NW-SE-attack.png` は3本のNW/SE全6コマを目視確認した比較。`weapon-glow.gif` は同じ描画コードから作成した3本の動作比較。
- `asset-validation.json` は12種の寸法・先端・不透明な握り・余白・ハッシュ・刀身マスク。`browser-validation.json` はブラウザ検証結果。
- 採用原画からの再構築で、12装備PNG・12単体PNG・3発光マスク・メタデータのSHA-256が再構築前と一致。
