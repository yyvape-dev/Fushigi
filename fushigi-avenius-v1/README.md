### 登録・体格

待機は256×256/原点(128,224)。動作は剣先を切らず体格を保つため320×256/原点(160,224)へ横の透明余白だけを拡張し、640×256アトラスに歩行/攻撃を収める。本編も動作幅とアンカーへ対応。描画倍率は全方向/動作で1.00。`build_motion.py` の原画の靴の測定範囲と接地点で登録し、身体のパーツを変形しない。解像度の差だけをシート全体の共通倍率で補正（歩行は中央値、攻撃は正面基準。しゃがんだ方向は無理に伸ばさない）。別解像度のNE修正原画はその画像全体を元シートの対応する身長へ等倍比率で合わせる。

2階以降、未同行・未撤退なら各階25%で助っ人に遭遇し、ユズナミキ/アベニウスを半々で選ぶ。会話で任意加入・0ターン。同行上限は従来どおり1人。追従/入れ替え/階段同行/敵標的/状態異常/撤退/冒険ごとのリセットを共有する。本人の顔・名前・台詞・HUD・状態へ切替。縦右手のHPは左下、縦左手は右下。ユズナミキの指定台詞・倍率1.20・接地点・能力は維持。

初期Lvは生成時の主人公と同じ。HP28＋4×(Lv−1)、最大Lv30、レベル上昇でHP＋4。攻撃＝主人公の現在の攻撃＋3＋0.8×(本人Lv−1)を四捨五入し、毒を引いて最低1。守備＝主人公の現在の守備＋⌊(本人Lv−1)/3⌋、最低0。閃光の剣・胴鎧で固定、装備絵や印をコピーしない。経験値は主人公/仲間へ各1回。数値は初期調整。

### 一閃

ユーザー指定の「4マスまで瞬間接近→先制攻撃→元位置へ帰還、敵1体につき1回」を実装。未指定部分は、見通しのある4マス以内（8方向の距離・直線以外も含む）の近い敵へ自動発動として補完。魔物部屋の未覚醒敵は除外。敵に隣接し、通行でき、元位置から見通せる床へ移動。主人公/敵/道具/罠と重ならず、同距離なら直進に近い床を選ぶ。着地点がなければ使用を消費しない。壁や塞がれた角を越えて殴らない。

必中、通常と同じ攻撃力/守備/ダメージ乱数。敵の行動前に解決する。攻撃時だけ着地点へ本人を移し、撃破/分裂後も `finally` で正確な元位置へ帰還。敵は帰還後の位置へ反応し、占有や罠発動を残さない。表示は360msの接近→剣攻撃→帰還と青い軌跡。敵オブジェクトを `WeakSet` に記録し、移動した同じ敵は再使用不可。同じ座標の新個体や分裂した新個体は別対象。使用済みの敵には隣接1マスの通常剣（通常命中率/地形判定）。眠り/混乱中は一閃を使わない。狐火は持たず、主人公の倍速の無料行動でも行動を増やさない。
