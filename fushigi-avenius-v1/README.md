## 今回の範囲

8方向の待機絵、256×256 RGBA、明示した靴の接地点、比較ページ、原画・プロンプト・ハッシュ・再現スクリプト。剣は本人の右手、白い花は左。左右反転なし。初稿のSWが正面に近く、NW/NEが真後ろに近かったため、承認デザイン・初稿・主人公の方向ガイドを参照し角度を修正。修正前の原画も保存。

待機基準絵は初版確認用。歩行・攻撃・一閃・本編の遭遇や同行への接続は未実装。既存の主人公、武器12種、盾10種、敵60種、ユズナミキ、本編HTMLは変更しない。同行上限は本編の1人のまま。

## サイズと足元

主人公の元マネキン `../fushigi-direction-base/direction-mannequin.blend` と `make_direction_guides.py` による方向ガイドをそのまま参照（約26度の正投影）。原ガイドの画像は `source-art/direction-guide.png`。本編基準の256pxキャンバス・原点(128,224)・192px基準身長を共有する。1マス64px時の基準身長は96px。確認画面は実寸と2倍を選択でき、縦画面でもCanvasを画面幅へ再設定して実寸を維持する。

`build.py` の `BOOTS` に、原画の剣・マントを含まない靴の測定範囲を明記。範囲内のアルファ100以上の左右中央、最下端−8原画pxを接地点とし、登録後の(128,224)へ平行移動する。正面の頭頂が採用済みラナのy=33になる共通倍率をシート全体へ適用する。方向ごとの拡大縮小・隠れた変形は使わない。描画倍率は1.00。

各方向の頭頂差は生成絵の形・投影の差として残す（`validation.json` の `crownYByDirection`）。足元は共通原点。正面はラナと頭頂を合わせ、剣先やマントの外形を身長・中心の基準にしない。実表示と全方向一覧を目視確認した。

## 再現と検証

```sh
python fushigi-avenius-v1/build.py
python -m http.server 8000 --bind 127.0.0.1
# 別ターミナル
python fushigi-avenius-v1/check.py
```

PillowとPlaywright・システムChromiumを使用。8枚の寸法・RGBA・アルファ・端の欠け・固有画像・非反転・ハッシュ・共通倍率・正面頭頂、390×844／844×390／320×640で16画像読込・8方向切替・実寸/2倍・ガイド切替・キーボード・自動方向切替・横はみ出し・JavaScript例外を検証。`validation.json` に結果を保存。`idle-contact.png` は全方向、`comparison-*.png` / `actual-size-*.png` はラナとの比較、`preview-*.png` は全体画面。

原画は `source-art/`、生成プロンプト・参照・原画のSHA-256は `generation-record.json`、登録画像と足元の測定情報は `ally.json`。`check.py` は `AVENIUS_REVIEW_URL` で公開先も検証可能。
