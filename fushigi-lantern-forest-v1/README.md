# 灯祭りの森 v1

ユーザー指定：森の中に少し開けた場所があり、ランタンやお祭りのような灯りがあるファンタジー。画風の基準は `source-art/concept.png`。画像だけでなく本編の森林ロケーションへ組み込む依頼に対応。

## 実装

- `forest` の床4種、壁側面2種、葉の上面2種、階段を規格書どおり256×256・不透明・lossless WebPへ更新。
- 2D/3Dとも、広場と道には6マス周期の連続した土の床 `floorW.webp` を使用する。
- 壁・天井は同じ青緑の葉の素材を4マス周期で共有。3Dでは壁の箱を低い茂みにし、木・ランタン・祭りの連灯を画像の板で追加する。
- `assets/dungeon/forest-festival-v1/` に単体512×512・マゼンタ背景PNGの木／ランタン／連灯。2Dは読み込み時に背景色を透過、3Dはシェーダーで抜く。生成時の灯りは小物の発光表現で、床テクスチャには照明を焼き込まない。
- 3Dは現在地に近いランタン最大6灯を点光源として使う。追加灯には影を付けない。森は青緑の環境光と控えめな主人公の光を使う。他ロケーションへ移ると従来の照明と壁へ戻す。
- 2Dでも木と灯りを同じ配置計画から描き、既存の視界・霧を後段で適用する。

## ランダム地形

`assets/forest-festival.js` が既存マップだけから装飾を決定する。`Math.random`・ゲームの乱数列・ターン・セーブを使わず、同じ階の地形なら読み直しても同じ配置になる。

- 木とランタンの取り付け位置は既存の壁マスに限定。
- 連灯は南側に2マス以上の奥行きがある長い北岸に沿って吊るす。幅1マスの道を横切る配置をしない。
- 階段の周り2マスは大きな装飾を除外。
- 最大6本の連灯と12個のランタン。木は床に接する壁のうち1マスおき。
- 地形生成、通行判定、アイテム・敵の配置は変更しない。広場や小道の形は既存のランダム生成器による。

木は実物の3Dモデルではなく、65度視点の絵をカメラに向けた板。葉が壁の外へ少し張り出すが、当たり判定を増やさない。完成コンセプトの細部やライティングを完全再現したと扱わない。

## 制作記録と再出力

原画は `source-art/`、プロンプトと参照条件は `generation.json`、出力の寸法・ハッシュは `manifest.json`。`garland-draft.png` は大きすぎた初稿を記録したもので、ゲームには使わない。

原画からの機械的な切り出し・縮尺・共通境界の組み立てはPython 3 + Pillowで実行：

```sh
python fushigi-lantern-forest-v1/export.py
python fushigi-lantern-forest-v1/verify.py
node tests/harness.js index.html tests/test_forest_festival.js
node tests/check_art.js
bash tests/run_all.sh
```

床4種・壁2種は共通の外周を使い、中央だけ模様を変える。検査は出力を復号し、全隣接組の上下左右の境界、異なる模様の存在、寸法、不透明性、天井との一致、背景色を確認する。
